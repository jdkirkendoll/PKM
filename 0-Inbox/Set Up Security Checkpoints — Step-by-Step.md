## Steps

Here are the step-by-step instructions for setting up security checkpoints:

1. **Enable the security checkpoint service**: Go to Solution Manager > Access Control > Security Checkpoints and toggle the switch to enable the service.

2. **Define a Security Checkpoint Gate (configuration)**:
    - Go to Solution Manager > Access Control > Security Checkpoints > New Security Checkpoint Gate.
    - Fill in the required information:
        - Unique ID
        - Description
        - Security Log message template with substitution parameters
        - Active/Inactive flag
    - Click Save and Close.

3. **Wire the gate into a business flow (implementation)**:
    - Go to Solution Manager > Access Control > Security Checkpoints > Gate Configuration.
    - Select the Security Checkpoint Gate you just created.
    - Go to the business flow that needs the security checkpoint and add a new action.
    - Select the Security Checkpoint Gate as the action and click Next.
    - Configure the implementation code as needed.
    - Click Finish.

4. **Decide the re-authentication behavior**:
    - Go to Solution Manager > Access Control > Security Checkpoints > Gate Configuration.
    - Select the Security Checkpoint Gate you created.
    - Go to the Gate Configuration page.
    - Configure the re-authentication behavior:
        - Default username behavior (fill in with current user's username, or require re-type)
        - Password authentication (default)
        - Comment field (optional)
        - OK and Cancel buttons
    - Click Save and Close.

5. **Runtime behavior once live**:
    - Go to Solution Manager > Access Control > Security Checkpoints > Gate Configuration.
    - Select the Security Checkpoint Gate you created.
    - Go to the Gate Configuration page.
    - Understand how the Security Checkpoint Gate works:
        - Only open during a transaction
        - Only first gate requires authentication by user
        - Security Checkpoint log is written
        - SECURITY_CHECKPOINT_SUCCESS event is executed on successful authentication
