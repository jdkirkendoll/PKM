# IFS Cloud Web Client Controls

## Summary

The IFS Cloud Web Framework offers a fixed catalog of client controls that a `.client` file can declare on a page. This note is the catalog index — most entries below are documented only by name in the source PDF; the ones this vault has a dedicated write-up for are linked.

## Details

Full catalog of client controls: Address Field, Arrange, Badge, Boolean, Box-matrix, Calendar, Card, Charts, Color Picker, Command, Computed Field, Contact Widget, Conditional Formatting, Currency Measure, Date Range Field, Date Time Picker, [[3-Resources/Glossary/Dialog|Dialog]], [[3-Resources/Glossary/Field|Field]], [[3-Resources/Glossary/Fieldset|Fieldset]], Free Text Field ([[3-Resources/Glossary/Free Input (Freetext Field)|Free Input]]), [[3-Resources/Glossary/Gantt Chart|Gantt Chart]], Grouping Field Set, [[3-Resources/Glossary/Grouping Field|Grouping Field]], [[3-Resources/Glossary/Image Viewer|Image Viewer]], In2AI, Item Picker, JSON Viewer, Kanban Board, List, List of Values, Markdown Text, Message Box, Multiline Field, Panel, Process Viewer, Progress Field, Radio Button, Rating Control, Search Context, Section, Selector, Sheet, Signature, Smart Editor, State Indicator, Static Field, Timeline, Toast, Tree, Tree Diagram, XD Viewer.

Controls with a dedicated glossary entry in this vault so far: [[3-Resources/Glossary/Dialog|Dialog]], [[3-Resources/Glossary/Field|Field]], [[3-Resources/Glossary/Fieldset|Fieldset]], [[3-Resources/Glossary/Free Input (Freetext Field)|Free Input (Freetext Field)]], [[3-Resources/Glossary/Gantt Chart|Gantt Chart]], [[3-Resources/Glossary/Grouping Field|Grouping Field]], [[3-Resources/Glossary/Image Viewer|Image Viewer]]. The rest are only named in the source documentation captured so far — no per-control PDF for them has been pulled into the local PDF library yet.
