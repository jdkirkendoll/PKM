# IFS Business Reporter — Designer's Guide

Version 22.1.0. Excel add-in reference guide for designing, publishing, and maintaining reports in IFS Business Reporter (BR) — covers basic and advanced report design, structure reports, writeback, and using native Excel functions within BR reports.

## Contents

1. Designing a Basic Report — selecting information sources, data access types, design rows/columns, repeaters, filter criteria
2. Designing an Advanced Report — advanced filter criteria, report parameters (standard, function, global), zoom-in, drill down, interactive filtering (workbook/sheet slicers), find, highlight, extended repeater connection
3. Save, Publish & Access Reports — saving, publishing, loading reports, refreshing information sources, ordering/scheduling reports, save report options (convert to PDF, remove connection)
4. Report Manager — downloading/validating reports, bulk save and republish
5. Writeback — complete/modified writeback, zero and null values, inserting new values, levels of writeback, transaction-level writeback, auto add new transaction row, design limitations
6. Structure Reports — static and dynamic structure repeaters, design limitations
7. Using Microsoft Excel Functions in IFS Business Reporter — Array, LOOKUP, OFFSET, MATCH, SUBTOTAL, INDIRECT
