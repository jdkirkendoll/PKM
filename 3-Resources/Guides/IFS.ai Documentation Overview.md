# IFS.ai Documentation Overview

Source: [docs.ifs.com/aidocs](https://docs.ifs.com/aidocs/). A comprehensive resource for implementing and adopting artificial intelligence within IFS systems, covering the AI platform components, governance, and embedded use cases across industries.

## Contents

- **IFS Loops Agentic Platform** — Powered by TheLoops, an enterprise platform that deploys "digital workers": AI agents that autonomously execute end-to-end business processes across connected systems, operating like new employees that improve via feedback toward 75–85% accuracy within months. Covers industrial agentic terminology, navigating/debugging a digital worker, adding tools, and connectors/integrations (IFS Cloud, MCP server setup, API integration, Slack, Teams, Outlook).
  - Digital workers documented: Customer Order Manager, Supplier Order Manager, Material Replenisher, Inventory Replenisher.
- **IFS.ai Copilot** — An AI assistant embedded in IFS Cloud that gives contextual support and answers questions across product areas (service management, procurement, HCM, maintenance, and more). Docs cover enabling the feature, access control via permission sets and system parameters, managing universal and page-specific prompts, the business objects that ground its responses, and an error log reference.
- **Machine Learning Services** — Customizable, trainable ML models rather than fixed pre-built types: send Machine Learning Data to the ML Service for a selected model, configure/map features to IFS Cloud data, set parameters, and train. Also offers separate pre-trained and large language model (LLM) offerings, plus ML configuration, data service configuration, and logs.
- **IFS.ai Embedded Use Cases** — AI capabilities built into IFS Cloud "to support smarter decision making, increased efficiency, and improved productivity," running on a shared IFS.ai Platform that integrates automatically with no customer setup required. Organized into ten industry categories: Finance, Projects, Manufacturing, Supply Chain, Service Management, Human Capital Management, Customer Relationship Management, Asset Management/Maintenance, Sustainability, and Experience Framework.
  - **Finance** — Payment delay prediction, supplier invoice data capture automation.
  - **Manufacturing** — Manufacturing scheduling and optimization (MSO), MSO simulation.
  - **Supply Chain** — Copilot for Customer Orders/Sales Quotation/Purchase Order/Shipment Order, customer order & sales quotation automation, summarised supply chain events, supplier quotation automation, time series forecast model, inbound delivery note automation.
  - **Asset Management/Maintenance** — Automated work order generation from documents, Copilot for work order execution, work order reporting data population, work task template optimizer.
  - Service Management, HCM, CRM, Sustainability, and Experience are also covered as categories, each with their own embedded use-case pages.
