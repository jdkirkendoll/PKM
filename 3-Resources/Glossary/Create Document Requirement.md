## Summary
A Document Requirement specifies which document classes must be generated for a business object — such as an engineering part revision, project part definition, or project item — before that object can be released. Requirements can be defined generically as a document requirement profile (which can then be assigned to a part class) or tailored individually for a specific part revision; each requirement names a document class plus up to five document categories, with the fuller document details entered later in Document Management. The resulting requirement list is visible in the object's Attachment Panel/Document Requirements, and if an object needs no documents, requirements simply aren't assigned to it.
