# Define Source Codes

## Summary

A Source Code records *how* a non-conformance was discovered on an NCR — for example through a quality audit, routine inspection, customer complaint, or day-to-day workflow. It's one of the standard NCR chart filter fields, used alongside [[3-Resources/Glossary/Define Severity Codes|Severity]], [[3-Resources/Glossary/Define Location Codes|Location]], and [[3-Resources/Glossary/Define Root Cause|Root Cause]] to see which detection channels are surfacing the most issues.
