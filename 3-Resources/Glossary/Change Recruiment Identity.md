## Summary

Recruitment identities are the automatically- or manually-generated key numbers used across the recruitment process — Personnel Requisition Number, Job Opportunity Reference Number, Applicant ID, and External Applicant ID. This activity manages/changes those identity series; the documentation specifically warns that switching between automatic and manual numbering can cause save errors if a unique ID is not available.
