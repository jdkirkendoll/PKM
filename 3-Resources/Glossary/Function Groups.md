# Function Groups

## Summary

Every voucher type in IFS Cloud belongs to a function group, which groups related voucher types together (for example, function group F covers customer invoices). Function groups, voucher types, and voucher number series are all created automatically when a new company is set up, but they need to be reviewed as part of basic data setup to confirm the groupings match how the business wants its transactions categorized and reported before go-live.
