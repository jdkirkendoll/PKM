# Define Detection Criteria

## Summary

Detection Criteria are the basic data used to score the "D" dimension of an FMEA — how likely existing controls are to catch a failure mode *before* it reaches the customer or next process step. Scoring runs from very likely to detect (low risk) to very unlikely to detect (high risk). Combined with [[3-Resources/Glossary/Define Severity Criteria|Severity]] and [[3-Resources/Glossary/Define Occurrence Criteria|Occurrence]], it completes the three inputs to the Risk Priority Number used to rank failure modes for corrective action.
