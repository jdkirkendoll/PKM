## Summary

Enter Note refers to attaching a free-text note or comment to a record such as an authorization rule, purchase requisition, or purchase order, using IFS Cloud's generic note/attachment functionality. Notes are used to record context (e.g., why a rule was set up a certain way, or special handling instructions) that doesn't have a dedicated field elsewhere on the page, and they stay attached to the record for anyone with access to review later.

> [!note] Confidence: moderate
> No dedicated IFS documentation page for this specific BDR line was found; this description is based on IFS Cloud's general-purpose note/attachment pattern used across many objects rather than a confirmed description of this exact activity.
