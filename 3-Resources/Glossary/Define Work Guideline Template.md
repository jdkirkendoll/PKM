# Define Work Guideline Template

## Summary

Work Guideline Templates let a manufacturer define a library of generic or standard work instructions — such as operational steps, safety/hazard warnings, and inspection notes — that can be reused across structures, routings, allocations, or operations rather than typed out each time. A work guideline can be created manually or generated from a template; when created from a template it is not permanently linked back to it, so later edits to the template are not automatically reflected in guidelines already created from it. When a shop order is created, the work guidelines attached to the structure and routing used on that order are copied onto the order's materials and operations respectively.
