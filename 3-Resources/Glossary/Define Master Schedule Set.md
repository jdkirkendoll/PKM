# Define Master Schedule Set

## Summary

A Master Schedule (MS) Set is the grouping/container object that Level 0 and Level 1 parts are connected to in order to be included in a given master scheduling run. It lets a company organize parts into logical planning groups (for example, by product family or by site) so that forecasts, calculations, and results can be managed and reviewed per set rather than for every part individually. Defining an MS Set is a prerequisite basic-data step for both Level 0 and Level 1 master scheduling: parts must be connected to a set (see Connect Level 0 Part to MS Sets) before Master Schedule calculations can be run against them.
