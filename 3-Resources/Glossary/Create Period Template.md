# Create Period Template

## Summary

A Period Template groups Planning Period Units into the time buckets used to display and analyze planning data in Master Scheduling (its primary consumer), as well as in MRP, Customer Schedules, and Rough-Cut/Resource Requirements Planning (RRP). A template can mix unit granularities over its horizon — for example, the first four periods as weeks, the next three as months, and the last three as quarters — so near-term planning is shown at fine granularity while the far horizon is compressed. Creating a Period Template is not mandatory for core MRP/MS calculations to run, but without one, related graphs and time-bucketed analysis views in Master Scheduling have no periods to group data into.

> [!note] Confidence: moderate
> This is well supported by an IFS Community discussion of Planning Period Units and Period Templates in Manufacturing Standard, but no official IFS Cloud documentation page dedicated specifically to the "Create Period Template" activity was found.
