# Alt Structure Rules

## Summary

Alt Structure Rules (documented by IFS as Structure Alternate Rules) are back-office configuration rules that operate within an already-selected configuration structure alternate to decide which structure components are included, based on the configured part's characteristic and option values. Their actions can also modify component data — for example adjusting Quantity per Assembly — according to the configuration. Where Structure Rules pick which structure alternate applies, Alt Structure Rules refine what that alternate actually contains, letting a single structure alternate yield different effective bills of material depending on how the part is configured.

> [!note] Confidence: moderate
> IFS Cloud documentation names this rule type "Structure Alternate Rules"; this entry treats it as equivalent to the BDR's "Alt Structure Rules" based on matching description and position in the rule hierarchy, but the exact screen/field name used in the product was not independently confirmed.
