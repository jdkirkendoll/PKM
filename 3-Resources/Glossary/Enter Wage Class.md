## Summary

A wage class groups employees who share the same set of wage codes, day types, and work-hour rules (typically corresponding to a pay basis or union agreement). The Get Wage Class calculation-formula function retrieves an employee's wage class on the current account date, and wage classes are also referenced by property codes such as WAGECLASS when transferring additional pay to Payroll.
