## Summary

The arrival location is where goods physically land when an arrival is first registered against a purchase order or shipment order, before any inspection or putaway happens. IFS Cloud picks the arrival location by priority — user-entered, then a default on the inventory part, then a default on the site, then the last location used — and for shipment orders received at a remote warehouse, a similar but separate priority chain applies (remote warehouse default, then latest receipt location for that warehouse).
