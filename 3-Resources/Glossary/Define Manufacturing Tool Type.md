# Define Manufacturing Tool Type

## Summary

Manufacturing Tool Type is the top level of IFS Cloud's tool-management hierarchy, used to group Tool Groups (IDs) that share similar characteristics — for example measurement tools, dies, jigs, fixtures, or test equipment. It is entered on the Manufacturing Tool Type tab of the Manufacturing Standard Basic Data window and is a prerequisite for creating any Tool Group or Tool Instance, since every tool group must be classified under a tool type. This classification underpins tool demand planning on routings/shop order operations and scheduling with tools as a finite resource in IFS Manufacturing Scheduling and Optimization (MSO).
