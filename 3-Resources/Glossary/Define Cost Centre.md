# Define Cost Centre

## Summary

A Cost Centre is a source of cost within IFS Cloud Activity Based Costing — it represents whatever grouping of expense the company wants to track and allocate, such as an energy cost pool or a department like HR. Cost centres are set up in two stages: the code itself is first registered as a value under Code Part Values (Cost Center part), then it is added as a record in the Cost Center window, which requires a Site to already exist. Cost centres are defined per Cost Set, so the same cost centre code can carry different costs under different costing scenarios. Once defined, a cost centre is linked to one or more Activities (each with its own allocation factor) so its cost can flow through to activity cost driver rates and ultimately to part costs.
