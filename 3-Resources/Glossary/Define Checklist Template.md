# Define Checklist Template

## Summary

A Checklist Template is a reusable, predefined set of steps/questions that can be attached to a quality record — FMEAs and MRB cases both use them. For MRB specifically, if a default checklist template has been set up for the non-conformance code entered on a case, it's applied automatically, standardizing the inspection/disposition process for that type of non-conformance rather than leaving it ad-hoc.
