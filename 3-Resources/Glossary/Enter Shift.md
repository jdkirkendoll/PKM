## Summary

In a cycle-type working hour schedule, a shift marks the allowed starting point(s) of the cycle — the sequence number(s) an employee can be linked to when assigned to that schedule. Simple one-week cycles typically need only one shift; multi-week or multi-team cycles need a shift defined for each parallel sequence so the scheduler can match the correct shift to each employee (named after the team/supervisor, not the working hours).
