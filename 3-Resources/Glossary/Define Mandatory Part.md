# Define Mandatory Part

## Summary

This basic data setting flags a specific part as requiring a Control Plan regardless of site, i.e. mandatory at the part level. When a part is marked this way, the system requires an active, valid Control Plan to be connected before the part can be received into stock — if none is connected, the part can only move to an arrival or QA location, not directly into inventory.
