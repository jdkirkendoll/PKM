## Summary

"360" refers to 360 Scheduling, described in IFS documentation as "a scalable optimization framework which conducts advanced mobile workforce scheduling" — wording that closely mirrors how IFS Cloud's current Planning and Scheduling Optimization (PSO) is described ("a scalable optimization framework which enables advanced scheduling of resources and activities"), strongly suggesting 360 Scheduling is an earlier or alternate product name/edition for the same underlying optimization engine, predating or paralleling PSO/DSE. This data point sets profile-level parameters for that 360 Scheduling configuration — object parameters such as the minimum work order status eligible for scheduling, the data-transfer protocol used, and a dataset ID prefix are documented as part of its setup.

> [!note] Confidence: moderate
> 360 Scheduling's existence and its relationship to PSO is confirmed by an IFS documentation mirror, but the exact fields on a "360 Profile Parameters" screen specifically weren't enumerated in what was found.
