## Summary

"Rule Collection" is a confirmed page in IFS Cloud's own Schedule Work Tasks with Scheduling Engine documentation. A Rule Collection groups individual Commit Rules together and is then linked to a Resource Type (per IFS Community forum discussion) — so a whole set of commit-eligibility rules can be applied to every resource of that type at once, rather than configuring rules resource-by-resource.
