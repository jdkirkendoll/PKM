# Link Project Cost/Revenue Elements to Accounts

## Summary

Once project cost/revenue elements are defined, each relevant code part value (account) must be mapped to one of those elements — for example, connecting every account that captures some form of material cost to a "Material" cost element. This mapping is what actually drives project cost/revenue reporting: without it, GL postings have no way to roll up into the element categories used for project follow-up. For hire billing, this step ensures hire cost and hire revenue accounts feed into the correct project cost/revenue element so hire projects can be analyzed consistently with the rest of project accounting.
