## Summary

Controls, via the SELFACCESS property code, whether an employee automatically has self-service access to their own employee record (Employee Files, Position/Job Assignment, Employee Schedules and Rules, etc.). If set to NO (the default), a user has no access to their own data unless it is explicitly granted through position access; set to YES, every employee can see their own record.
