# Define Classification Criteria

## Summary

Classification Criteria in FMEA basic data provide the categories used to group or tag failure modes (for example by risk class or by which product/process characteristic they affect), separate from the three numeric scoring criteria ([[3-Resources/Glossary/Define Severity Criteria|Severity]], [[3-Resources/Glossary/Define Occurrence Criteria|Occurrence]], [[3-Resources/Glossary/Define Detection Criteria|Detection]]). This classification is what lets an FMEA be filtered, reported on, or connected to a [[3-Resources/Glossary/Define Checklist Template|Checklist Template]] by category.
