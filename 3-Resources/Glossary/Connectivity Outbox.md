# Connectivity Outbox

## Summary

The Connectivity Outbox is the administration screen for messages waiting to leave IFS Connectivity's Out Message Box. Messages can be explored by Class ID, State, Media Code, or Today's activity, viewed in full detail, and exported/imported as XML. A message moves from `Posted` to `Released` (ready to transfer) through `Processing` to `Transferred`, ending in `Accepted`, `Rejected`, or `Failed`. An `Incomplete` message can be **Reactivated** back to `Released`, and a `Transferred` message can be **Reprocessed** back to `Released` to retry the transfer.
