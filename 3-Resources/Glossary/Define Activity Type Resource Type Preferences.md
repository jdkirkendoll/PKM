## Summary

Similar to Activity Type Resource Preferences, but expressed at the coarser Resource Type level (e.g. "prefer a Senior Technician resource type") rather than naming individual resources — letting an activity type favor a category of resource for allocation by the scheduling engine without pinning it to one specific person.

> [!note] Confidence: moderate
> Consistent with the documented "preferred resource" scheduling input and the separately-documented Scheduling Resource Type concept, but this specific preference screen was not explicitly documented.
