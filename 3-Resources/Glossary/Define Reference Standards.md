# Define Reference Standards

## Summary

A Reference Standard is a compliance benchmark or framework (e.g. an ISO standard or customer-mandated standard) that audits are performed against. Compliance Planning uses reference standards as one of its core axes: identifying which standards apply to each [[3-Resources/Glossary/Define Business Area|Business Area]], and letting you pull up all planned audits against a specific standard when planning the year's audit schedule.
