## Summary
An Approval Template defines a reusable, ordered set of approval steps that can be applied to a business object — such as an engineering part revision or a document revision — to automatically generate its approval routing. Each step can require one or more approvers (individuals or groups), can allow parallel approval by several people at once, and can optionally require an electronic signature or security authentication. Templates are created in the Document Basic window's Approval Template tab (the same generic template mechanism is reused from Product Basic Data and other modules), given a short ID and description, and become available for selection wherever approval routing is set up, including on Engineering Part Revisions in the Design Standard Product area. All designated approvers must already exist as Oracle users with defined User IDs in the system.
