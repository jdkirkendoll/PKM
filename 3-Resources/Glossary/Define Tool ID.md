# Define Tool ID

## Summary

Tool ID (documented as Tool Group ID) identifies a group of tools and equipment that share the same functional characteristics, one level below Manufacturing Tool Type in IFS Cloud's tool hierarchy. A Tool Group ID can be added to routings and shop order operations to register a tool demand for that operation, and it can be connected to usage guidelines and calibration requirements that apply to every tool instance in the group. When a shop order operation is scheduled, the required tool group can optionally be satisfied by assigning a specific tool/equipment instance from within it.

> [!note] Confidence: moderate
> IFS Cloud documentation for the Manufacturing Tool window consistently uses the term "Tool Group ID" rather than "Tool ID." This entry treats the BDR wording "Define Tool ID" as referring to that same field, since no separate "Tool ID" concept distinct from Tool Group ID was found.
