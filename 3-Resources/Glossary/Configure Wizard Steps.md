## Summary

Several Employee Administration processes (such as New Employment and Terminate Employment) run as a configurable wizard/assistant made up of a sequence of steps; this activity configures which steps appear and in what order, so the guided process matches the company's own onboarding/termination procedure (for example, extra steps appear automatically if IFS/Payroll or IFS/Job Security are installed).
