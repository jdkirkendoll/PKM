# Create Work Centre

## Summary

A Work Center is a specific production area where an operation is performed — typically one or more machines capable of the same job, or a physical assembly area — and it is the core resource that IFS Cloud Manufacturing schedules against. Creating a Work Center establishes it as either an Internal Work Center (used for internal operations on routings and shop orders, scheduled via Capacity Requirements Planning, driving machine load and cost calculation and operation-reporting control), an Outside Work Center (representing a supplier's subcontracting capacity for external operations), or a Resource Requirements Planning (RRP) work center (for master scheduling with flexible, non-hour capacity units). Creating the work center also auto-creates a default resource with the same name, which can later be supplemented with additional resources. A work center can optionally be assigned to a department and/or a production line.
