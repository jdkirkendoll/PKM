# Connect Level 0 Part to MS Sets

## Summary

This step assigns a defined MS Level 0 Part to one or more Master Schedule Sets so it becomes part of a runnable master scheduling group. Without this connection, a Level 0 part's forecasts cannot be included in a Level 0 master schedule calculation or disaggregated down to its Level 1 parts. It is the link between the two other basic-data steps — Define Master Schedule Level 0 Part and Define Master Schedule Set — and is a required setup step before Level 0 forecasting and calculation activities can be performed.
