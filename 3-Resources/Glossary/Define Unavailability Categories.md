## Summary

Classifies the types of unavailability a resource can have — the confirmed examples in IFS Cloud documentation being absences, training allocations, project allocations, breaks, and lunches — so each can potentially be treated differently by the scheduling engine (e.g. hard vs. soft constraint, or included/excluded from certain reports).

> [!note] Confidence: moderate
> The underlying unavailability types (absence, training, project allocation, breaks, lunches) are confirmed; a dedicated "Categories" configuration screen for them specifically was not separately documented.
