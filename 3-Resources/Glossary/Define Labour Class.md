# Define Labour Class

## Summary

Labour Class (Labor Class) is basic data used in IFS Cloud Manufacturing to set and differentiate labor cost rates, complementing work-center-based machine costs which apply uniformly regardless of activity. A routing operation can be assigned different labour classes for setup time versus run time, so the two can be costed at different hourly rates rather than a single blended rate. Labour Class is also a scheduling constraint in Manufacturing Scheduling and Optimization (MSO), which considers work centers, labour classes, and manufacturing tools together; if a person or person group's labour class is marked Exempt Labor, labor capacity is excluded from MSO's finite-capacity scheduling for that resource.
