## Summary

Multi-supplier ordering splits a single purchase requirement among several suppliers based on predefined split percentages, so manufacturing isn't blocked if one supplier is late, high volumes can be spread across vendors, or multiple supplier relationships can be maintained deliberately. It only applies to demand from MRP, Master Scheduling, Order Point, Next Level Demand, or manually entered requisitions for inventory- or non-inventory-registered purchase parts (not acquisitions from another order), and suppliers can be phased in/out over non-overlapping periods as long as each period's percentages total 100%. The split quantity is rounded up to each supplier's standard multiple quantity before ordering.
