# Define Schedule Report Points

## Summary

Report Points let a Production Line report progress against a production schedule at intermediate stages, not just at final completion, so component inventory can be updated more frequently than end-item-only reporting would allow. To use report points, a production routing must already be defined for the part built on the line; each report point is then set to coincide with a specific range of operation steps in that routing. As production moves through the line, quantity is reported at each defined report point and again at final completion, giving planners more granular visibility into work-in-process than a single completion report would.
