# Define Inspection Codes

## Summary

An Inspection Code is basic data (up to 20 characters) shared between Inventory and Quality Management that determines how much of a receipt gets inspected — either a fixed quantity or a percentage of the arrived quantity. On a purchase receipt it drives the inspection rule applied at arrival; when Quality Management/Control Plans are active, it works alongside the Control Plan's own sample-size calculation (via Acceptance Sampling) to determine the quantity to inspect. Default inspection codes can also be set per supplier-and-purchase-part combination, so different suppliers or parts can carry different inspection requirements automatically.
