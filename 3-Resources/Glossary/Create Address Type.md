# Create Address Type

## Summary

Address Type is generic IFS Cloud basic data that classifies the addresses that can be attached to a business object — for a Sales Contract this typically means distinguishing addresses such as site/delivery address, invoicing address, or correspondence address held against the contract. Defining Address Types lets a contract carry multiple addresses for different purposes while keeping their roles unambiguous for billing, delivery, and correspondence.
