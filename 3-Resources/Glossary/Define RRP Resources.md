# Define RRP Resources

## Summary

Beyond machine time, Resource Requirements Planning (RRP) lets a company define other key resource types to capacity-check against the plan — for example storage space, personnel, transport capacity, or supplier capacity. Each RRP resource is tied to a work center and given a capacity and a load source, where the load source decides what consumes that capacity during calculation: unconsumed forecast/demand, supplies created by master scheduling or sales & operations planning, or projected on-hand versus a maximum. This capacity data is auto-populated from the work center/load source but can be adjusted per resource, and additional scenarios with different capacity/load parameters can be attached once those scenarios are registered.
