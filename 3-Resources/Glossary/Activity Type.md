# Activity Type

## Summary

Activity Type specifies whether a Business Activity is a Meeting, Task, Call, Chat or E-Mail. Together with Connection Type (which defines whether the activity is registered against a lead, account, supplier request or supplier), Activity Type controls the layout of the business activity page and the visibility of certain fields. The CRM/SRM Default Values page's "Valid Activity Types" setting restricts which activity types a user (e.g. a sales representative) can pick when manually creating an activity — types like Chat are typically reserved for activities generated automatically by a workflow or integration. Activity Sub Types can further refine an activity's nature within a given Activity Type.
