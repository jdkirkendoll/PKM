## Summary

Balance reconciliation compares a time balance's value at the end of a defined period against configured rules (a fixed value, or a minimum/maximum), adjusting it if necessary and optionally moving any remainder to another balance or wage code. This activity defines the reconciliation period the comparison runs against, and reconciliation can be triggered automatically at that periodicity or run manually at any time.
