## Summary

In IFS Cloud's Planning and Scheduling Optimization (PSO), Exceptions are schedule events that may need manual intervention — flagged in the Scheduling Workbench's Exception panel and in the Dispatch Console's Exceptions view. Each Scheduling Exception has a Scheduling Exception Type (defined based on resource-, activity-, or other conditions), and this data point covers setting up those exception types and their associated threshold/attention values, which control when and how prominently an exception is surfaced to a dispatcher. Users can acknowledge an exception with a comment once it's been dealt with.
