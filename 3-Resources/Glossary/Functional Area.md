# Functional Area

## Summary

A Functional Area is a named grouping of security objects — Projections, Projection Actions, Projection Entities, and Entity Actions — that represents one business function, such as "Goods Receiving." Functional Areas exist so that administrators can define rules about which business functions should, or must not, be accessible to the same user, and can be created, edited, and imported/exported as XML from Solution Manager's Segregation of Duties section. Two Functional Areas can be paired into a **Functional Area Conflict**, marked as **Warning** or **Not Allowed** severity, with an optional flag for whether activity performed through a Workflow counts toward the conflict. These conflict definitions are the input that Segregation of Duties Analysis checks against actual user grants.
