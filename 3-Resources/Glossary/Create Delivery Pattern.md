## Summary

A delivery pattern is basic data (created under Procurement Basic Data → Delivery Patterns) describing a supplier's recurring delivery schedule — for example which weekdays deliveries typically arrive. Once created, a pattern can be connected to purchase parts/suppliers so the system can suggest realistic expected delivery dates for requisitions and orders tied to that recurring cadence.

> [!note] Confidence: moderate
> Confirmed that Delivery Patterns exist as a Procurement Basic Data tab; the exact scheduling mechanics were not confirmed in a dedicated source.
