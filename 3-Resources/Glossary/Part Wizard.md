## Summary

The Part Wizard is a guided dialog for creating a new part in IFS Cloud that walks the user through the part type decision up front — e.g., Purchased Inventory Part or Purchased Non-Inventory Part — and then only asks for the fields relevant to that type. For a purchased inventory part, entering the inventory part information is enough and the system automatically generates the corresponding purchase part; for a purchased non-inventory part, the buyer fills in the Purchase Part tab directly since there is no inventory part behind it.
