# Set Up Priority Rule(s) per Site

## Summary

Shop Order Priorities are configured per site as priority categories, each carrying an adjustment factor that raises (factor above 100) or lowers (factor below 100) a shop order's relative importance. Once a priority category exists for a site, it can be selected in the Priority Category field on a shop order's Settings and Options, which then influences the sequencing IFS Cloud uses during automatic shop-order processing (reservation is sequenced by priority first, then revised start date, then shop order number) and during scheduling on the Advanced Planning Board. The same priority category can also be used to sort operations shown on the Shop Floor Workbench.
