# Define Manufacturing Engineer

## Summary

Manufacturing Engineer is basic data configured in the Manufacturing Standard Basic Data window (Manufacturing Engineer tab) that identifies the individuals who can be assigned responsibility for Part Transfer / Engineering Transfer activity — moving engineering (PDM) part data into manufacturing sites. Each engineer is selected from a list of values and can optionally be marked "Blocked for Use" to stop further assignment. If a blocked engineer is currently set as a site's default, the system prompts to specify a replacement engineer so the default stays valid across affected sites. This basic data is a prerequisite for setting up the default engineer/planner per site and for running engineering transfers at all.
