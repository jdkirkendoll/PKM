# Set-up contract revision id's

## Summary

IFS Cloud's Sales Contract Management provides "comprehensive contract revision control with baselines and audit trailing," meaning a contract's content can be revised (for example after a review phase or when a contract change order/variation order is approved) while retaining a full history of prior baselines. Setting up contract revision IDs defines the numbering or identification scheme used to distinguish these successive contract revisions/baselines, so each version of the contract can be uniquely referenced, audited, and rolled back to if needed.

> [!note] Confidence: moderate
> The local documentation confirms contract revision control and baselining as a core capability, but does not show the exact configuration screen or fields for the revision ID scheme itself. The setup purpose is inferred from the documented revision-control behavior.
