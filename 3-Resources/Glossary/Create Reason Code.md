# Create Reason Code

## Summary

Reason Codes are basic data used on Sales Contracts to record why a particular outcome occurred. IFS Cloud's documented contract lifecycle explicitly calls for registering a reason when a contract is Awarded (why it was won) and when a contract is marked Lost (why the customer chose not to proceed, e.g. a competitor won instead). Capturing these reasons via standardized codes lets the business analyze win/loss patterns and improve future bidding.
