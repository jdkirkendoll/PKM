# Define Control Plan Checklist

## Summary

A Control Plan Checklist is a set of predefined inspection/verification steps that can be attached to a Control Plan, so that inspectors work through a consistent, standardized list of checks each time an analysis is created for a part rather than relying on ad-hoc inspection. It's the Control Plan equivalent of the checklist templates used elsewhere in Quality Management (see [[3-Resources/Glossary/Define Checklist Template|Define Checklist Template]]) — defining what gets checked and in what order for parts/processes governed by that plan.
