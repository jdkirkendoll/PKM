## Summary

This data point configures parameters for a server-side profile abbreviated "TMS" within the Scheduling area's PSO/DSE suite. Generic IFS material defines "TMS" elsewhere as "Transportation Management System," but that product is unrelated to this field-service scheduling engine, so that expansion almost certainly does not apply here. Within scheduling/workforce-optimization tools generally, "TMS" more often denotes a Territory (or Task) Management component that governs how work is grouped and routed to resources by geography — a plausible but unconfirmed fit alongside this suite's Regions and Resource Region concepts.

> [!note] Confidence: low
> No IFS documentation or forum content defining "TMS" in this scheduling-engine context was found. The territory-management interpretation is inferred from common industry usage, not confirmed against IFS material.
