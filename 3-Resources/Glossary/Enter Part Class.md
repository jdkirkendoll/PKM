## Summary
A Part Class groups similar engineering parts into common categories — for example "cables," "hardware," or "mechanics" — sitting one level below Main Group and above Standard Name in the PDM classification hierarchy. Part classes are created (optionally, usually by an administrator) in the Product Basic Data window's Classes tab, with a class ID of up to 10 alphanumeric characters plus a description. Beyond simple categorization and search/reporting filters, a part class can also be connected to a document requirement profile so that the right document classes are automatically required for every part assigned to it, and Engineering Part Revisions documentation notes that standard documentation requirements can be assigned either at the part-class level or tailored per revision.
