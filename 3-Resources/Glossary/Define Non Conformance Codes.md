# Define Non Conformance Codes

## Summary

A Non Conformance Code classifies *what kind* of non-conformance is being recorded on an MRB case or Non Conformance Report (NCR) — e.g. the category of problem found. It's one of the core fields used to filter and analyze NCRs, and it can also drive automation: if a default [[3-Resources/Glossary/Define Checklist Template|Checklist Template]] is configured for a given non-conformance code, that template is applied automatically when the code is selected.
