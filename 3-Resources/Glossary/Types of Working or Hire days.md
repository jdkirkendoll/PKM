# Types of Working or Hire days

## Summary

In IFS Cloud Rental Management, the number of days a hired asset (equipment, or a company vehicle handled as an internal rental) is actually billed for is driven by basic data rather than a simple calendar count. A "Chargeable Days" definition sets which days of the week count as chargeable/working hire days, and this is combined with a Date Exceptions calendar and a Period Rounding setting to work out exactly how many days in a given hire period are billable. As a Basic Data Requirement, someone must decide and configure which day-of-week pattern applies (e.g. Monday–Friday only vs. every day) before hire/rental transactions can be generated correctly.
