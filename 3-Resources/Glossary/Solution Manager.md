# Solution Manager

## Summary

Solution Manager is IFS Cloud's central administration console for day-to-day customer-side configuration and operation. Its scope goes well beyond security — it also covers Background Processing, Integration, Data Management, Mobile Apps, Object Connections, Configuration, Automation and Optimization, Reporting and Analysis, Monitoring, Workflow Manager, License Management, IFS.ai Copilot management, and more — but the Access Control section is where all Permission Set, Functional Area, Segregation of Duties, and Identity and Access Manager administration happens: creating, duplicating, comparing, deleting, exporting/importing, and granting Permission Sets; defining Functional Areas and their conflicts; running Segregation of Duties Analysis; and configuring the IAM.
