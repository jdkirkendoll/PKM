## Summary

Warehouse task type setup defines, per site and task type (of the six predefined types: Customer Order Pick List, Transport Task, Shop Order Pick List, Shipment Order Pick List, Project Deliverables Pick List, and Purchase Receipt Return Pick List), the values that control how tasks of that type behave: a numeric Priority (1 highest to 99999 lowest, used as a default when the task source doesn't supply one), a Default Time Needed per line (used as a planning default), and a Start In Status of Planned or Released. Warehouse tasks of a given type are only created at all once that type is activated for the site.
