# Opportunity Stage

## Summary

Opportunity Stage tracks where a Business Opportunity sits within its assigned CRM sales process — a typical example process has the stages Qualify, Propose, Negotiate and Close, each with its own default Probability and set of mandatory/optional actions the sales representative must complete (controlled by a Validation Type of None, Notify, or Stop) before the opportunity can advance. In IFS Cloud's CRM analysis model, Opportunity Stage is exposed as a dimension built from a code + description combination.
