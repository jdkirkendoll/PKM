## Summary

Position access lets a set of access roles be assigned to a position rather than to an individual, so that whoever currently holds the position automatically receives the associated access rights over subordinate positions/employees. This is one of the methods (alongside direct access-role assignment) used to grant supervision rights in the Organization and Position access setup.
