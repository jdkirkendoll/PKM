## Summary

Similar to "Define activity templates," but for use within a Modelling Dataset — i.e., templates used to generate representative/synthetic activities for what-if capacity-planning scenarios (the "Distributed" process type documented for capacity planning in this suite) rather than for real scheduled work. This lets planners model demand without needing real Work Tasks for every scenario they want to test.
