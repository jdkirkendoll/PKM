## Summary

A Service Project is the top level of a documented hierarchy in IFS Cloud's Work Processing area: Project > Request / Request Quotation > Scope > Task > Resource Demand. The Service Project Capacity Planning & Scheduling page gives planners/dispatchers a Gantt-based workspace to visualize, schedule, and allocate work across this whole hierarchy, including capacity planning, task-dependency visualization, and work-assignment creation, with integration into the Dispatch Console, Schedule Assistance, and PSO (EPSO) dispatchers.
