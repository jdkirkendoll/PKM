# Create Competitor

## Summary

Competitor is basic data used on Sales Contracts to register the other companies bidding for the same tender. IFS Cloud documentation notes that when a contract is marked Lost, this can be because "a competitor wins the contract instead," and the reason for the loss is registered for later analysis. Maintaining a list of competitors lets the business track which competitor was involved in a lost bid, supporting win/loss analysis and future bidding strategy.
