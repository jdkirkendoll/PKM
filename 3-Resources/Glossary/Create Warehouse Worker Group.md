## Summary

Warehouse management assigns work using a matrix of task types against inventory location groups (zones), and each worker is connected to at least one such zone plus the task types they're qualified for. Worker groups let you manage that connection for a set of workers together rather than one at a time, so warehouse tasks (customer order picks, transport tasks, shop order picks, etc.) can be automatically offered to the right pool of qualified people for a given zone.
