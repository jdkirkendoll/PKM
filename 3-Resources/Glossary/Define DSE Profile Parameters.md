## Summary

DSE stands for the Dynamic Scheduling Engine — IFS Cloud's own name for the automatic scheduling/optimization component of Planning and Scheduling Optimization (PSO), confirmed directly in the local IFS docs corpus ("If IFS/Dynamic Scheduling Engine is used and is to use a resource, it needs to be registered in Scheduling Basic Data"). This data point sets the profile-level parameters that drive how the DSE behaves for a group of resources or a dataset — for example, whether competencies/certificates are sent as skill constraints, whether a skill hierarchy is respected, or how plan-change acknowledgements are handled — mirroring the kind of global/dataset-level parameters documented for the related "Define Scheduling Configuration" activity.

> [!note] Confidence: moderate
> DSE itself is confirmed as the Dynamic Scheduling Engine. The exact set of fields on a "DSE Profile Parameters" screen specifically (as distinct from the general Scheduling Configuration page) was not found and is inferred by analogy.
