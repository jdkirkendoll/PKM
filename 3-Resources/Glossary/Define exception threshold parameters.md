## Summary

This is the parameter-level counterpart to "Define Exceptions and thresholds" — setting the specific attention-value thresholds that determine when a Scheduling Exception Type is raised and how urgently it's flagged to a dispatcher in the PSO Scheduling Workbench and Dispatch Console. IFS Cloud documentation notes users can also define custom exceptions directly in the PSO workbench beyond the standard set shipped with the product.
