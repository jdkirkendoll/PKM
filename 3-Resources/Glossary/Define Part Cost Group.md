# Define Part Cost Group

## Summary

A Part Cost Group is costing basic data in IFS Cloud that groups inventory parts sharing similar costing characteristics — for example manufactured parts versus purchased parts — so a default cost template can be assigned to the whole group at once rather than to each part individually. Each Part Cost Group carries a default cost template at header level, which determines which cost buckets and cost elements are used when the system calculates cost for any part connected to that group. Defining Part Cost Groups up front speeds initial costing setup across large part populations and is a prerequisite for the related "Assign Part Cost Group to Part" and template override activities.
