# Market

## Summary

Market (Sales Market) is a basic-data value that identifies which market segment an account or lead is connected to, defined as a code plus description. It is shared basic data used by both the CRM and Sales analysis models, and is also one of the parameters (alongside Representative, Account, Country, Potential, Source, etc.) that can be weighted to determine which default CRM qualification or sales process is automatically assigned when a lead or opportunity is created.
