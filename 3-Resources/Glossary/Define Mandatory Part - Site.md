# Define Mandatory Part / Site

## Summary

This basic data setting makes a Control Plan mandatory for one specific **part-at-a-specific-site** combination, rather than for the part everywhere ([[3-Resources/Glossary/Define Mandatory Part|Define Mandatory Part]]) or for every part at a site ([[3-Resources/Glossary/Define Mandatory Site|Define Mandatory Site]]). It's the most granular of the three mandatory-control-plan settings, letting you require inspection for a given part only when it's received at particular sites.
