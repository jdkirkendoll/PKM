## Summary

Records which tools/equipment a specific resource carries or is qualified to use, so the scheduling engine can match tool-requiring activities (see "Define Activity Type Tools") only to resources that actually have the needed tool, mirroring the confirmed skill-matching pattern used for Resource Skills.
