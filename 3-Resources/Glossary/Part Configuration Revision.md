# Part Configuration Revision

## Summary

A Part Configuration Revision is the revision- and date-controlled record where characteristics and options are actually selected for a specific configurable part, drawn from those defined for the part's Configuration Family. Each revision progresses through Tentative, Test, Released, and Obsolete statuses; only a Released revision, effective as of the relevant due date, can be used for live sales quotation, order, and manufacturing configuration. This lets a new set of characteristics or options be introduced and tested for a part without disrupting configurations already built on an earlier, still-Released revision.
