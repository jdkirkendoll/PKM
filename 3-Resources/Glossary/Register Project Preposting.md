## Summary

Registers pre-accounting (preposting) information at the project level, so that transactions connected to the project (for example from Expense Administration) inherit consistent code-string information rather than requiring it to be entered on every transaction — controlled in part by the ORGPREPOST property code, which decides whether organization-level or project-level preposting fills gaps in an expense sheet's project accounting.
