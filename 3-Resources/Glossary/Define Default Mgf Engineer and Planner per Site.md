# Define Default Mgf Engineer and Planner per Site

## Summary

This basic data, entered on the Engineering Transfer Site Role tab of the Manufacturing Standard Basic Data window, assigns a default Manufacturing Engineer and default Planner to each manufacturing site. It requires three fields per record: site, planner, and manufacturing engineer. Once set, these defaults are automatically applied whenever an engineering (PDM) part is transferred into that site, so parts don't need to be assigned an engineer or planner manually on every transfer. It depends on Manufacturing Engineer already being defined, since the engineer field is selected from that list of values.
