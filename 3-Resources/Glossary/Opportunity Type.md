# Opportunity Type

## Summary

Opportunity Type is a basic-data value that specifies the nature of a Business Opportunity, letting the organization categorize and later analyze opportunities by kind (for example, to compare estimated versus actual opportunity value across opportunity types). It is exposed in IFS Cloud's CRM analysis model as an attribute on the Business Opportunity dimension, carrying both a code and a description.

> [!note] Confidence: moderate
> The corpus confirms the field exists and its general purpose ("specifies the nature of the opportunity") but does not enumerate the specific type values a company would configure — these are set up as CRM basic data per implementation.
