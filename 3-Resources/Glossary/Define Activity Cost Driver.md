# Define Activity Cost Driver

## Summary

An Activity Cost Driver is the Activity Based Costing equivalent of a cost element: a quantitative measure of an activity's output that triggers cost attribution from an activity to the parts consuming it. IFS Cloud supports two kinds — transaction drivers, which count how often an activity occurs and suit outputs with equal demand on the activity (e.g. number of setups, number of issues); and duration drivers, which measure the time an activity takes and suit outputs where that time varies by part (e.g. labor setup hours, machine runtime hours). The system ships with several pre-defined drivers, and additional ones are created in the Activity Cost Drivers window with an ID, description, and driver source. The rate the driver ultimately carries is calculated by dividing the relevant cost center's cost by the estimated usage of the driver.
