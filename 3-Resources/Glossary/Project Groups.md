# Project Groups

## Summary

A Project Group is basic data in IFS Project Management that every project must be assigned to. It defaults behavior for the individual project — such as project type and reposting rules — which is inherited when the project is created but can still be overridden at the project level. For hire/rental billing, defining project groups up front means every project-based hire job of a given category (e.g. equipment hire projects) automatically gets consistent accounting and processing defaults, instead of each project needing to be configured from scratch.
