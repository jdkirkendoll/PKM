# Create Category 1

## Summary

Category 1 is a user-defined classification code that can be assigned to a Sales Contract for grouping, filtering, and analysis purposes — for example, by business line, contract size band, or internal reporting segment. It works alongside a second independent classification, Category 2, so contracts can be sliced along two separate dimensions simultaneously in reporting and lobbies.
