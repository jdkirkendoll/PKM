## Summary

In the Wage Codes/Specified Overtime setup, this activity defines wage codes that summarize the overtime hours worked within a day's time interval and then distribute those hours sequentially across a series of overtime wage codes (e.g. the first two hours to OT-1, the next four to OT-2, and so on).
