# Define Cost Parameter

## Summary

This activity is where a site's Cost Parameters are first configured in IFS Cloud Costing, using the Cost Parameters tab of the Costing Basic Data window. The system ships a fixed list of parameters rather than letting users create arbitrary new ones — items such as Inventory Scrap Factor (Purchased Parts), Inventory Scrap Factor (Manufactured Parts), Copy Estimated Material Cost, ROI period, ROI period limit, reinvestment rate, financial rate, Number of Products/Parts for ABC analysis, Operation Cost Warning, Include Non-Consumed Components, and the SO start date basis for variance bookings. Defining these correctly at site setup is a prerequisite for accurate Cost Rollup, Kaizen ROI, and ABC analysis results later.

> [!note] Confidence: moderate
> The distinction between "Define Cost Parameter" and "Set Cost Parameter" as separate BDR steps is not explicit in the source documentation — both appear to map to the same Cost Parameters tab of Costing Basic Data.
