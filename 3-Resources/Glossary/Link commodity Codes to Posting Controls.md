# Link commodity Codes to Posting Controls

## Summary

Commodity codes classify inventory/purchase parts by category (a taxonomy used mainly for procurement analysis and spend classification). Linking commodity codes to posting control lets postings for a group of parts be driven by their commodity classification — so, for example, all hire equipment under a given commodity code posts to the same account — instead of requiring posting control to be set up part-by-part.

> [!note] Confidence: moderate
> Commodity codes and the general control-type mechanism for posting control are both confirmed independently in IFS sources, but no documentation was found describing commodity codes as a control type feeding posting control directly, so the linkage described here is inferred rather than verified.
