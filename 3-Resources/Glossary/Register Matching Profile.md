## Summary

A matching profile is the qualification profile (competencies, certifications, education, work experience) a person's qualifications are compared against in Gap Analysis, which represents the gaps graphically (e.g. via radar charts) and calculates a compatibility percentage for each qualification component against a job, another person, or a qualification profile.
