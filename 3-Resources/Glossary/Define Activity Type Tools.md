## Summary

Defines which tools/equipment an activity of a given Activity Type typically requires, analogous to Activity Type Skills and Activity Type Parts, so that this requirement can be inherited by every activity of that type rather than set individually each time.

> No IFS documentation specifically describing tool requirements at the Activity Type level was found. Inferred by analogy with the documented Activity Type Skills pattern and the standalone "Define Tools"/"Define Resource Tools" basic data in this same BDR.
