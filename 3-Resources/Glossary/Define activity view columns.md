## Summary

This activity configures which data columns are displayed for each activity (scheduled Work Task/Request Task) row in the Scheduling Workbench/Dispatch Console's activity list or Gantt view, analogous to "Define resource view columns" but for the activity side of the schedule. It lets dispatchers customize which fields — such as SLA status, priority, or location — are visible at a glance.
