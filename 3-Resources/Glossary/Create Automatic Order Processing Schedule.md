## Summary

Automatic order processing (AOP) can release purchase requisitions and purchase orders, convert requisitions to orders, and print/send/e-mail purchase orders, depending on which events are enabled on the applicable order processing type. The AOP batch job that performs this work can be run manually or on a defined schedule (day and time), so this activity is about setting up that recurring schedule so qualifying requisitions/orders are processed automatically instead of requiring a user to run the batch by hand.
