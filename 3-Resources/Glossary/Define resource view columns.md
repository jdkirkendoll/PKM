## Summary

This activity configures which data columns are displayed for each resource row in the Scheduling Workbench/Dispatch Console's Gantt-style resource view — for example resource name, region, skills, or utilization — letting a dispatcher tailor the resource list to what matters for their planning work. This is a standard UI-personalization feature in Gantt-based scheduling tools rather than something with unique business logic of its own.
