# Characteristic Language

## Summary

Characteristic Language basic data holds the language-specific text (name/description, and the text for each Discrete Option value) for a Configuration Characteristic, so the same characteristic displays correctly to users and customers working in different languages during Sales Configurator or CTO configuration. It follows IFS Cloud's general Basic Data Translation pattern used across other master data.
