## Summary

Purchase requisition authorization rules are created in the Purchase Requisition Authorization Rule page and decide which authorization routing template applies to a requisition line, based on criteria such as requisitioner, supplier, purchase group, pre-posting code parts, project category, and an amount interval. Options on the rule control whether amendments are allowed after partial/full authorization, whether an unauthorized requisition can be converted to a request for quotation, and whether the rule applies to project-connected lines. As with order rules, when multiple released rules match a requisition line, the one with the highest priority (lowest number) is used.
