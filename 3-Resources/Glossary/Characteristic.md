# Characteristic

## Summary

A Characteristic (configuration characteristic) is an attribute used to describe a configurable part in IFS Cloud's Configure To Order (CTO) functionality — for example color, capacity, or voltage. Characteristics come in three value types: Discrete Option, which offers a finite list of possible values; Variable Value, which allows a numeric range or free alphanumeric entry; and informational characteristics, which exist for reference only and don't affect the physical product or its configuration identity. Characteristics are grouped into a Configuration Family and are the values that back-office Structure and Routing Rules evaluate to decide which components, operations, tools, and work guidelines apply to a specific configured part.
