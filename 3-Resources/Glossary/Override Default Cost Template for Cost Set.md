# Override Default Cost Template for Cost Set

## Summary

This activity overrides the default cost template assigned to a Part Cost Group, but scoped to one specific Cost Set rather than the group as a whole. It is performed from the Part Cost Group or Part Cost Group/Cost Set windows and lets an organization use a different cost template for the same parts in different cost sets — for example, standard cost (Cost Set 1) could use one template while a what-if or planning cost set uses another. This supports running multiple cost reiterations and alternative versions (what-if scenarios) side by side without disturbing the group's default template.
