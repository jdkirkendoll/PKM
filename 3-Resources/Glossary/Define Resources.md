# Define Resources

## Summary

This activity defines the individual resources (machines, tools, or equivalent capacity units) that exist within a Work Center in IFS Cloud Manufacturing. When a work center is registered, IFS Cloud automatically creates one resource matching the work center's own name, but this function lets additional resources be added under the same work center — for example, several distinct machines that share the work center's routing/scheduling context. Each resource is given a short Resource ID (up to five alphanumeric characters), a description, an optional Object ID linking it to the corresponding object in IFS Maintenance, a validity period (start date, optional end date), and an Efficiency percentage (default 100%) used in capacity calculations. Resources — not just work centers — are what IFS Cloud actually schedules against and reports capacity for in CRP and Advanced Planning Board.
