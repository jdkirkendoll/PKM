## Summary

Overview Supplier is a read-oriented summary view that surfaces a supplier's key data (general, address, purchasing, financial) in one page for quick review, rather than the entry-focused Supplier page used to create/edit records. It's typically what buyers or AP staff use to confirm a supplier's setup before referencing it on a document, complementing the detailed entry tabs covered elsewhere in this group.

> [!note] Confidence: moderate
> Inferred from the naming convention used by other "Overview" screens in IFS Cloud (e.g., Overview Inv. Locations); a dedicated source confirming this exact supplier overview page's contents was not found.
