## Summary

Defines a preference for specific individual resources to be favored (or avoided) by the scheduling engine when allocating an activity of this Activity Type — IFS Cloud's documentation confirms "the preferred resource for the work" is one of the inputs the engine considers, alongside resource skills, cost, location, and activity urgency, when producing an allocation.

> [!note] Confidence: moderate
> The general concept of a "preferred resource" as a scheduling input is confirmed; whether this preference is configured specifically at the Activity Type level (as this BDR row implies) versus elsewhere was not explicitly documented.
