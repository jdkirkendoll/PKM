## Summary

Attributes determine properties/characteristics of an object, useful for grouping and finding data with specific characteristics. IFS Cloud's Resource Attribute Manager documentation for this scheduling suite confirms three attribute types: Resource, Shift, and Scheduling — each determines which kind of object the attribute can be attached to. Some attributes are system-defined (shipped with the installation) and others can be user-defined. Attributes and their values are created and maintained in the Resource Attribute Manager, and more specifically-defined attributes (e.g. set at Shift level) take priority over broader ones (e.g. set on the Scheduling Resource page) when the data is sent to the Dynamic Scheduling Engine (DSE).
