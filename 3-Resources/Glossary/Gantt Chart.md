# Gantt Chart

## Summary

The Gantt Chart control gives a graphical, page-only (not usable in an assistant) view of a schedule for planning, coordinating, and tracking tasks — a tree-like "data grid" on the left (flat or hierarchical, built from `ganttcolumn` definitions) paired with time-based bars ("Gantt items") on the right. It's declared for an entity (`ganttchart ProjectGantt for Project { ... }`) and populated either from its own dedicated entity set or from the hosting page's entity set. Beyond the basics, the control supports a large set of configuration areas: hierarchical grouping, schedule/connection display, item styling and coloring, cards for extra info/actions, CRUD actions and custom commands, filtering, a legend, time markers, cross-Gantt subscriptions, timescale/zoom/time-range configuration, multi-select, snap-time behavior, row grouping, display time zone, and lazy-loading of item attributes for performance on large datasets.
