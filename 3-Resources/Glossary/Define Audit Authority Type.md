# Define Audit Authority Type

## Summary

Audit Authority Type categorizes the *kind* of body that holds authority over an audit or reference standard — for example a certification body, a regulatory agency, a customer, or an internal authority — before naming the specific [[3-Resources/Glossary/Define Audit Authority|Audit Authority]] itself. This two-level type/instance pattern (type, then specific authority) mirrors how Reference Standards are tied to Business Areas in Compliance Planning.
