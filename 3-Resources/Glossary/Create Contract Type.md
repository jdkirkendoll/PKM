# Create Contract Type

## Summary

Contract Type is basic data used to classify Sales Contracts (e.g. by commercial arrangement or business line) before they are created. IFS Cloud's Sales Contract Management supports contracts that can be developed with or without an attached project, carry default values (retentions, markups, payment terms, currency), and progress through a defined lifecycle from Enquiry through Close. Setting up Contract Types lets an organization group and default-configure contracts consistently at creation time rather than repeating the same setup on every contract.

> [!note] Confidence: moderate
> The local IFS Cloud documentation confirms Sales Contracts carry default values and lifecycle behavior, but no source found describes a distinct "Contract Type" basic-data screen by name or its exact fields. This entry infers the purpose by analogy with the "Type" basic data pattern used elsewhere in IFS Cloud (e.g. Order Type, Customer Order Type) to classify similar business objects.
