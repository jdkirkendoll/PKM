## Summary

Resource Groups are a confirmed mechanism in IFS Cloud's scheduling engine documentation for expressing a resource's skill: "Resource Groups that the resource belongs to will be transferred as a resource skill along with a skill proficiency if a proficiency has been defined on the Resource Group." A proficiency can speed up or slow down a Work Task's estimated execution time; if several resource groups with different proficiencies apply to one activity, the lowest proficiency is used. Resource Groups demanded by a Work Task must be matched by the Resource Groups a resource belongs to for allocation to succeed.
