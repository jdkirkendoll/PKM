# Define/Maintain Standard Operation

## Summary

A Standard Operation lets a commonly used manufacturing operation be defined once and then copied or referenced into many routings and routing templates, instead of re-entering the same operation data repeatedly. When a routing operation references (rather than copies) a standard operation, subsequent edits to the standard operation can be propagated out to every routing that references it, keeping shared operation data consistent across a site. Maintaining a Standard Operation means updating that shared definition — work center, labor/resource data, work guidelines, tooling — on the Standard Operation page itself, from where the changes can later be pushed to dependent routings.
