# Assign Cost Element to Cost Bucket

## Summary

This activity connects individual Cost Elements to a Cost Bucket so that the bucket's total reflects the sum of those elements — cost buckets are, by definition, built up from cost elements. It applies to buckets of type Bucket of Element (the standard predefined-bucket type); a small set of trigger elements (141, 230, 501, 502, 601) cannot be connected directly into a cost bucket. The system ships default buckets with their elements pre-assigned, and the connection can also be made or reviewed from the Cost Elements, Overhead Cost Definition, or Define Overhead Cost pages.

> [!note] Confidence: moderate
> No single official documentation page titled exactly "Assign Cost Element to Cost Bucket" was found; this is built from the Define Cost Bucket and Cost Elements documentation, which describe the bucket-to-element relationship but not a standalone named activity.
