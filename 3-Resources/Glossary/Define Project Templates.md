## Summary

IFS Cloud's Work Processing area documents a Service Project hierarchy — Project, Request/Request Quotation, Scope, Task, and Resource Demand — visualized and scheduled via the Service Project Capacity Planning & Scheduling Gantt page. A Project Template would pre-define a reusable structure of Requests/Scopes/Tasks for a common type of multi-task Service Project, letting planners create new projects of that kind quickly rather than building the hierarchy from scratch each time.

> [!note] Confidence: moderate
> The Service Project hierarchy itself is confirmed in IFS Cloud documentation; the specific "Project Template" configuration screen for pre-defining that hierarchy was not directly documented in what was found.
