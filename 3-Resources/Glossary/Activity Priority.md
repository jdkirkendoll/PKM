# Activity Priority

## Summary

Activity Priority is a basic-data value that indicates the importance of a Business Activity, letting sales representatives and managers triage which activities (calls, meetings, tasks, etc.) need attention first. It is exposed in IFS Cloud's CRM analysis model as the Business Activity Priority dimension, built from the DIM_BUSINESS_ACTIVITY_PRIORITY dimension with a code and description.
