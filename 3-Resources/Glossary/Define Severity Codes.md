# Define Severity Codes

## Summary

A Severity Code rates how serious a recorded non-conformance is on an NCR. It's one of the standard fields an NCR chart can be filtered and analyzed by (alongside [[3-Resources/Glossary/Define Location Codes|Location]], [[3-Resources/Glossary/Define Source Codes|Source]], and [[3-Resources/Glossary/Define Root Cause|Root Cause]]), letting quality teams triage and report on non-conformances by how much impact they have.
