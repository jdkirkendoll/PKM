# Enter Basic Data for Work Centre Department

## Summary

A Work Center Department is the organizational grouping a Work Center can belong to in IFS Cloud Manufacturing, alongside (or instead of) belonging to a Production Line. IFS Cloud documentation confirms this relationship directly — "a work center can belong to a department and/or a production line" — but the department itself is largely a classification/reporting grouping rather than a data point that drives scheduling or costing the way the work center's own capacity and cost settings do. Departments are typically used to group work centers for reporting, cost roll-ups, or organizational views of the shop floor.
