## Summary

The purchase component method, set on the Site/Sales and Procurement/Procurement/General page, decides how components supplied to an outsourcing supplier are handled — the main option is Customer Order, which drives the charge/no-charge flow (a customer order is created to reserve, pick, and ship the material, and it can optionally be charged to the supplier). This setting becomes the default for newly created purchase order component lines and determines which basic data (customer connection, order type, etc.) must be in place before outsourcing purchase orders can be processed.
