# Accounting Groups

## Summary

Accounting Groups are basic data used to cluster objects that should share the same posting behavior — for example a set of parts, customers, or suppliers that should all post to the same accounts — so posting control can be defined once per group instead of once per individual object. This keeps posting control setup manageable as the number of parts/customers/suppliers grows, and for Asset Management it lets rented equipment or hire-related items be grouped so their financial postings follow a consistent, group-level rule.

> [!note] Confidence: moderate
> A general community reference confirms "Accounting Groups" exists as an IFS Cloud concept, but the specific behavior described here (grouping objects to share posting control) is inferred from how accounting/posting groups work generally in IFS Cloud's posting control framework, not verified against a page describing this exact screen.
