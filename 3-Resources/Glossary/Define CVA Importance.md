# Define CVA Importance

## Summary

CVA (Customer Value Added) Importance is basic data used in IFS Cloud's Quality Function Deployment (QFD)-style costing analysis, where it defines the set of importance ratings (e.g., a scale of levels such as low/medium/high or numeric weights) that can be assigned to a customer requirement. These ratings are later used together with Customer Requirements/Product Features to weigh how much value each requirement contributes relative to its cost, supporting target-costing and value-analysis decisions about where design or cost-reduction effort should be focused.
