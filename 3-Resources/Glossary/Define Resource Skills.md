## Summary

IFS Cloud documentation confirms a resource's skills are transferred to the scheduling engine from several sources rather than typed in directly on one screen: the Resource Groups the resource belongs to (each with an optional proficiency that speeds up or slows down the estimated execution time), Certificates and Competencies held by the associated HR employee (competencies only if enabled via Scheduling Configuration), and the Sites the user has access to via their maintenance organization. Skill hierarchy (respecting the relative levels/points of certificates and competencies) can optionally be enabled. For a Work Task activity to be allocated to a resource, its skills must match the skills required by the activity.
