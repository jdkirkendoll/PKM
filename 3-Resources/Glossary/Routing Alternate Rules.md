# Routing Alternate Rules

## Summary

Routing Alternate Rules are back-office configuration rules that select which routing alternate applies to a configured manufacturing order, evaluating the part's configured characteristic and option values in the same condition/action manner as Structure Alternate (Alt Structure) Rules do for structures. Selecting the routing alternate is the first step in resolving a configured routing — once chosen, Routing Operation Rules, Routing Operation Work Guideline Rules, and Routing Operation Tool Rules refine which operations, guidelines, and tools within that alternate actually apply.
