# Won/Lost Reason

## Summary

Won/Lost Reason records why a Business Opportunity's closed status ended up won or lost. When an opportunity is manually closed as lost, the user can specify which competitor won the business and the reason for the loss; when an order is created from a won opportunity, the user can enter the reason it was won. In IFS Cloud's CRM analysis model this is exposed as the WIN LOSE REASON dimension, built as a code + description combination on the DIM_WIN_LOSE_REASON dimension.
