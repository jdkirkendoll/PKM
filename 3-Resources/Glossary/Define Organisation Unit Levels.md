## Summary

An organization structure is a hierarchical tree of organization units (departments, production lines, offices, etc.) that reflects how a company or matrix organization is structured. This activity defines the levels of that hierarchy (e.g. division, department, section) that organization units can be created under, giving the tree a consistent shape before individual units are defined.
