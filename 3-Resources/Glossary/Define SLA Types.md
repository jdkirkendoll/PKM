## Summary

A Scheduling SLA Type is confirmed IFS Cloud basic data ("part of the Scheduling Basic Data") that defines values such as start/end proportions and curve shape, used by the Dynamic Scheduling Engine (DSE) to calculate the urgency of an activity or break. Scheduling SLA Types, combined with an activity's base value, determine its scheduling priority/behavior. A dataset can define default Primary and Secondary Scheduling SLA Types to fall back on when a Work Task is missing one, and an Activity Type can define default durations for those SLA types.
