## Summary

An authorization rule (purchase requisition or purchase order) must be in Released status before the system will use it to check documents and fetch an authorization routing template — a rule that is still Planned is ignored. Releasing a rule is therefore the final basic-data step after entering its criteria and template; a released rule stays in effect until closed, and a new rule with the same priority can only be released once the old one is closed.
