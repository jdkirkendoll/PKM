## Summary

A site can have a default arrival location, inspection location, and/or stock location, which the receipt function falls back to when no more specific default is found — for example, when the inventory part doesn't have its own default location, or when using it as the last-used-location fallback. Setting these site-level defaults ensures receipts always have somewhere to go even for parts that haven't been individually configured with their own default locations.
