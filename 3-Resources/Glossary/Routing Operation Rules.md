# Routing Operation Rules

## Summary

Routing Operation Rules are back-office configuration rules attached to individual routing operations. Their conditions — Boolean expressions evaluated against a configured part's characteristic and option values — determine whether a specific operation is selected for inclusion in that configuration's routing, and their actions can set operation attribute values or declare derived characteristics. Together with Routing Alternate Rules (which pick the routing alternate) and Routing Operation Work Guideline/Tool Rules (which refine what's attached to a selected operation), they let one routing definition produce different effective operation sequences depending on how the part is configured.
