# Define Labour Cost

## Summary

Labour cost basic data is defined per labour class, cost set, and period, with a cost driver of either hour or percentage; labour overhead can additionally be defined as a percentage of the labour class cost per hour. When the system calculates labour cost it always factors in crew size, which is set when routings are registered on a routing operation. These values become Cost Elements 210 (setup) and 220 (runtime), rolled into Cost Bucket 200, and are used to calculate both the standard labour cost of a manufactured part and the actual labour cost of reported shop order time.
