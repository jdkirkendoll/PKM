# Define RRP Unique Work Centres

## Summary

Resource Requirements Planning (RRP), IFS Cloud's rough-cut capacity planning tool, checks whether a manufacturing plan is feasible by balancing planned capacity against required capacity for constraining resources. RRP can reuse ordinary manufacturing work centers, but it also supports creating work centers that exist solely for RRP purposes — "RRP unique work centres." Unlike standard work centers, an RRP-unique work center can be defined in any unit of measure appropriate to the constraint being tracked (e.g. pieces, square meters, liters, or kilos), which lets RRP model non-machine constraints such as storage space, personnel headcount, or supplier capacity that a real production work center wouldn't represent.
