## Summary

This activity is entering the supplier's address data — street, city, postal code, country, and address type — on the Address tab of the Supplier page. It is a required step alongside General Info before the supplier can be used, and it feeds default addresses that more specific tabs (Purchase Address, Payment Address) can then override for particular transaction types.
