## Summary

The customs statistics number is the code (from Inventory Basic Data/Customs Statistics No) that customs authorities use to classify a part for Intrastat reporting — for example, a specific code for leather clothes versus coat hangers. Every inventory part must be connected to one for Intrastat to work, and each customs statistics number also determines whether the part must be reported by net weight or by a supplementary unit (pieces, liters, etc.), plus the conversion factor between that unit and the part's inventory unit of measure.
