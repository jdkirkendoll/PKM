# Copy Work Centre from other Work Centre

## Summary

This function lets a new Work Center be created by copying the setup of an existing one rather than entering every field from scratch — useful when a site has multiple work centers with near-identical capacity, cost, or resource configuration (for example, duplicate machines on a line). Copying carries over the source work center's configured attributes so only the differences (ID, description, and any site- or machine-specific values) need to be changed afterward, saving setup time when standing up new production capacity.
