## Summary

An inventory part can have its own default arrival location, inspection location, and stock location, which take priority over the site-level defaults when the receipt function looks for where to place received goods (the priority order is: user-entered, then the inventory part's default, then the site's default, then the last-used location). Setting these per-part defaults is how a specific high-volume or specially-handled part always lands in the right place without the receiving clerk having to pick a location manually each time.
