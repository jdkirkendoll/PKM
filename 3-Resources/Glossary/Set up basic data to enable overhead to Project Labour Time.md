## Summary

Sets up the basic data needed so that an overhead amount is automatically calculated and posted (via the PRJT3/PRJT4 Project Labor Overhead posting types) whenever an employee's project time transaction is approved for cost accounting, adding an indirect-cost loading on top of direct labor cost.
