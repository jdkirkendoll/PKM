## Summary

Purchase order authorization rules are created in the Purchase Order Authorization Rule page and determine which authorization routing template applies to a purchase order (or its change orders) based on criteria such as buyer, supplier, supplier statistic group, coordinator, project, and an amount interval. Options on the rule control whether changes are allowed after authorization (No Changes Allowed, Within Order Amount, Within Authorizer Limit), whether charge amounts count toward the authorized amount, and whether the rule applies to the original order, change orders, or both. When several released rules match a given order, the rule with the highest priority (lowest priority number) is applied.
