# Define Activity

## Summary

In IFS Cloud Activity Based Costing (ABC), an Activity represents one of the (typically 10-15) most important operations a company performs that consume resources — for example labor setup, machine runtime, or material handling. Activities are defined in the Cost Activity window, where each is given an Activity ID and description and is paired with an Activity Cost Driver that will measure its output. When an activity is created, the system automatically creates a corresponding cost bucket with the same identity, which accumulates the costs later attributed through that activity. Activities are the foundation ABC uses to trace overhead costs to parts more accurately than a single blanket overhead rate.
