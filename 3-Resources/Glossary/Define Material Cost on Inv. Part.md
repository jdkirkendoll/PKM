# Define Material Cost on Inv. Part

## Summary

This basic data defines the direct material cost of an inventory part — entered and maintained per cost set via Part Cost / Part Cost Details — which IFS Cloud Costing stores as Cost Element 110 ("estimated material cost"). Cost elements are the smallest cost-generating items (material, work centre, or labour) that roll up into Cost Buckets and, ultimately, Cost Templates used to calculate a part's standard or actual unit cost. Defining material cost is Object Costing basic data — it feeds the cost roll-up engine but is distinct from the Cost Set configuration (standard vs. actual costing) that consumes it.
