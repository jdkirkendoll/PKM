# Assign Activity to Cost Centre

## Summary

An Activity must be linked to a Cost Centre before Activity Based Costing can pass costs down to the final cost carrier (the part). This assignment is made on the Cost Center Activities tab of the Cost Center window, where each activity attached to a cost centre is given an Activity Cost Factor — the percentage of that cost centre's total cost allocated to the activity — and an Estimated Driver Quantity, the expected volume of the activity's cost driver over the period. A single cost centre can fund multiple activities, provided their Activity Cost Factors sum to 100%, and a single activity can draw from several different cost centres. This factor and quantity, together with the cost centre's total cost, are what the system uses to calculate the activity cost driver rate.
