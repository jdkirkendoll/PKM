# Assign Cost Buckets to Cost Template

## Summary

A Cost Bucket groups related cost elements into a single cost category (for example, bucket 200 combines labor setup and runtime, bucket 300 combines machine setup and runtime). A Cost Template determines which buckets make up a part's total cost and enables rapid, consistent cost set-up by connecting those buckets to the inventory parts that will carry them. IFS Cloud ships with pre-defined templates — manufacturing (e.g. M-110), purchasing (P-110 through P-150), and core (C-110 through C-150) — each with its own predefined set of assigned buckets (M-110, for instance, includes buckets 200, 201, 221, 300, 321, 322, 400, and 421); this basic data point covers assigning or reviewing which buckets belong to a given template, which in turn decides what cost categories are included when the part's cost is calculated.
