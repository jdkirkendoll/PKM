# Group

## Summary

Group (Representative Group) is CRM basic data used to collect Representatives into named groups, each with its own description — for example to organize sales representatives by team, region or line of business. Representative groups are also used for access control: when a record's representative is a member of a group, other members of that group can be granted access to the record according to the privileges configured for the group.
