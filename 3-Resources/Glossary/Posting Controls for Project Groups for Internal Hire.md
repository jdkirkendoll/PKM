# Posting Controls for Project Groups for Internal Hire

## Summary

"Internal hire" covers equipment rented between sites or projects within the same company rather than to/from an external party. For rental orders between sites in the same company, IFS Cloud creates an inter-site voucher that posts internal cost (to the hiring site/project) and internal revenue (to the owning site/project) based on the rental order's events and values. Posting control keyed on Project Group lets this internal cost/revenue split post automatically to the right accounts for each project group involved, without requiring an external invoice between the two sides.

> [!note] Confidence: moderate
> The inter-site voucher / internal cost-and-revenue mechanism for rentals between sites is confirmed in IFS documentation, but the specific "project group" control-type configuration for this scenario was not verified against a dedicated documentation page.
