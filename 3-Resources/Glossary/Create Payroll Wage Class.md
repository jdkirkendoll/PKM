## Summary

Wage classes group employees (typically by pay basis, e.g. salaried vs. hourly, or by union agreement) so that a set of wage codes, schedules, and posting rules can be applied consistently to everyone in the class. Booking Payroll uses the wage class to determine how a payroll run's results should be posted to the general ledger.
