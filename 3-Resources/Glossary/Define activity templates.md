## Summary

An activity template pre-populates the recurring scheduling attributes of a Work Task/Request Task activity — such as duration, required skills, parts, and tools — so new activities of a common kind can be created quickly and consistently rather than configured from scratch each time. This is distinct from "Define Activity Types" (the classification/category an activity belongs to, which is well documented for this suite); a template is closer to a reusable starting-point definition.
