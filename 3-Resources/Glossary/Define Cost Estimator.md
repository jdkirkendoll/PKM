# Define Cost Estimator

## Summary

Cost Estimator in IFS Cloud Costing identifies the person (or organizational role) responsible for the cost calculation of a product. A Cost Estimator is set up as a Person record in the system, but that person does not have to be an actual system user — organizations commonly define a role like "Engineering Department" or "Technical Manager" as the Person instead of a named individual. Defining Cost Estimators as basic data is a prerequisite for assigning one to a part, which is used later to filter the Part Costs overview by who is responsible for its cost calculation.
