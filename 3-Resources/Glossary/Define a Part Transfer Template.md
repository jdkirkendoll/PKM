# Define a Part Transfer Template

## Summary

A Part Transfer Template is basic data (created in the Part Transfer Template window) that classifies how a part should be handled when it is transferred from Engineering (PDM) into a manufacturing site, keyed by part type. Typical templates cover the standard part-type classifications — Manufactured (MAN), Purchased (PUR), Purchased Raw (RAW), and Expense (EXP) — each carrying a unique template ID, description, and part-type classification that drives what data the system creates on transfer (e.g., inventory part revision, manufacturing or prototype structure). Templates must exist before a default template per site/part type can be configured.
