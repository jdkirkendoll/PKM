## Summary

Order processing types are basic-data records (set up in Procurement Basic Data) that define which events — release, convert requisition to order, print/send/e-mail — the automatic order processing batch should perform for the requisition or purchase order lines connected to that type. The order processing type can be set directly on a requisition/order line or defaulted from the purchase part record, letting different categories of purchase get different automation behavior (e.g., some auto-release and auto-print, others just auto-release).
