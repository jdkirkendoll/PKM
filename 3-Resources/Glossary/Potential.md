# Potential

## Summary

Potential is a basic-data value that grades the importance or value of a lead or account — essentially how promising the deal looks. It is configurable per company; a typical example setup uses values like Hot, Cold, Hibernate, Lost and Win. In IFS Cloud's CRM analysis model it is exposed as the CustomerPotential dimension (with a code and description) built on the business activity fact table, so it can be used to segment and report on leads by how likely/valuable they are.
