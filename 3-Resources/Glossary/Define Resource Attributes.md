## Summary

Resource is one of the three confirmed attribute types in this suite's Resource Attribute Manager (alongside Shift and Scheduling). A documented system-defined Resource attribute exists for regions: it can define region availability for a resource under either Automatic Scheduling (DSE) or Manual Scheduling (Dispatch Console), and when set with a validity period on the Resource Attributes tab, it takes precedence over the base region defined on the Scheduling Resource Regions page for that date range. If a resource is relocated, its relocated region is likewise recorded as a resource attribute for the relocation period.
