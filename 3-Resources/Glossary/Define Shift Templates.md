## Summary

A Shift Template defines a reusable work-shift pattern that can be assigned to resources. IFS Cloud's Resource Attribute Manager documentation confirms Shift as one of three attribute types (alongside Resource and Scheduling), with system-defined scheduling attributes usable "in the Shift template or directly at the Shift level" — for example Cost per KM, Address Start/End, Snap Time, and Overtime. Values set at the Shift Template or individual shift level take priority over the broader default set on the Scheduling Resource page for that date range when data is sent to the Dynamic Scheduling Engine (DSE).
