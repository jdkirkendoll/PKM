# Define Occurrence Criteria

## Summary

Occurrence Criteria are the basic data used to score the "O" dimension of an FMEA — how likely a given failure mode is to happen, typically scaled from "failure unlikely" (well under 1% frequency) up to "failure inevitable" (a high frequency, e.g. over 5%). Together with [[3-Resources/Glossary/Define Severity Criteria|Severity]] and [[3-Resources/Glossary/Define Detection Criteria|Detection]] criteria, this produces the Risk Priority Number used to prioritize which failure modes need attention first.
