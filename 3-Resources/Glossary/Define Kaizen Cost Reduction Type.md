# Define Kaizen Cost Reduction Type

## Summary

Reduction Type is basic data used within IFS Cloud's Kaizen Costing functionality, which supports the Kaizen methodology of pursuing continuous, incremental cost reductions throughout the manufacturing lifecycle. Defining a Reduction Type gives users predefined categories to classify Kaizen cost-reduction initiatives, and a Reduction Type can be tied to activities at specific Cost Centers so improvement efforts can be organized and tracked by area of the business. It is used alongside Kaizen Cost Items and Kaizen Status (Initiated, Preliminary, Approved, etc.) as part of setting a target cost, comparing it to actual cost, and driving corrective action when targets are missed.
