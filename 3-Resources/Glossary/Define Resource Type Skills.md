## Summary

Defines a baseline set of skills that every resource of a given Resource Type is assumed to hold, so individual resources inherit them without needing to be tagged one at a time — consistent with the documented inheritance pattern where a resource without its own scheduling data picks up defaults from its Resource Type.

> [!note] Confidence: moderate
> The general inheritance-from-Resource-Type pattern is confirmed for scheduling costs and shift locations; its extension to skills specifically was not explicitly documented and is inferred by analogy.
