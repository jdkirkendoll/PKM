# Routing Operation Tool Rules

## Summary

Routing Operation Tool Rules are back-office configuration rules that govern which tools are required for a routing operation on a configured part. Conditions evaluate the part's characteristic and option values to decide whether a given tool applies to the operation, and actions can adjust tool-related attributes accordingly. Alongside Routing Operation Work Guideline Rules, these are the mechanism that lets a single routing operation carry different tooling requirements depending on how the part is configured.
