# Define/Maintain Routing Template

## Summary

A Routing Template is a generic, standardized routing that provides a quick way to define routing details for a part without recreating the same sequence of operations from scratch each time, and it can be applied to many parts at once. Creating one manually is done on the Routing Template page: operations are defined on the Operations tab, work guidelines or tools can optionally be attached, and the Where Used tab shows which parts currently reference the template. Prerequisites include already having defined work centers, labor classes (if used), tool groups, and any work guideline templates. Templates can be applied to a part either by copying (a one-time snapshot) or by reference — and when referenced, later changes to the template affect every routing originally created from it, unless that routing has since been manually modified; only standard operations defined for the same site as the template can be copied or referenced into it.
