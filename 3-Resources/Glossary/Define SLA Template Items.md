## Summary

The individual lines within an SLA Template, each carrying its own Duration, Calendar, Fulfillment Entity/Event, and optional Scheduling SLA Type connection, as documented for IFS Cloud's SLA Template concept. Multiple lines let one template create several distinct SLA Commitments (e.g. one for a Request-level response SLA and another for a Work Task completion SLA) from a single template.

> [!note] Confidence: moderate
> The SLA Template's line/item structure is confirmed in IFS Cloud documentation, though the source refers to them as "Template Lines" rather than the BDR's "Template Items" — treated here as the same concept under a slightly different name.
