# Copy Period Template

## Summary

This function duplicates an existing Period Template as the starting point for a new one, rather than building the period/unit breakdown from scratch — useful when a company needs several templates that share most of the same structure (for example, the same near-term weekly buckets but a different far-horizon grouping for a different site or planning purpose). It supports the same use cases as Period Templates generally: grouping Planning Period Units into time buckets consumed by Master Scheduling, MRP, and RRP.
