# Commodity Codes

## Summary

Commodity Codes (called Commodity Groups in the IFS Cloud UI) are basic data used to categorize Inventory Parts for reporting, planning, and default-value purposes. Up to two commodity groups can be linked to an inventory part: Commodity Group 1 is used purely to group similar types of parts together (e.g. for searching/sorting), while Commodity Group 2 can additionally carry default values — such as minimum statistical periods — that flow into the part's planning data when Calculate Planning Data is run. For rental/hire equipment, setting these up before go-live lets parts be grouped consistently for reporting and lets planning defaults be inherited rather than entered part-by-part.
