# Voucher Series per FY

## Summary

Each voucher type in IFS Cloud is linked to one voucher number series per fiscal year (or per period, if the "Use Voucher Number Series Per Period" option was enabled for the company). These series are created automatically when a new company is set up, but before each new fiscal year they must be confirmed or extended so that vouchers keep numbering correctly and no transaction fails to post because a series for the upcoming year is missing.
