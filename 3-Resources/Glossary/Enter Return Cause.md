## Summary

Return causes are basic data (entered on the Return Causes page) recording why goods were returned to a supplier during inspection — for example, a quality problem or a mistaken delivery. A receipt line's return can be typed as Return for Rework (the supplier bears the cost of reworking) or Return for Credit (the supplier issues a credit invoice or invoices only the approved parts, and a replacement order can be created); the return cause is what documents the reason behind that decision for follow-up and for the supplier returns report.
