## Summary

A Scheduling Resource equals a person or crew resource in IFS Cloud that can be scheduled by the Dynamic Scheduling Engine (DSE) — confirmed directly in IFS Cloud's PSO documentation ("A scheduling resource equals a person or crew resource in IFS Cloud... Scheduling engine schedules one resource to one activity"). For a resource to be usable, its employee must be set up in IFS Human Resources, belong to the scheduled company, be assigned a valid maintenance organization/resource group, and have valid geo-coordinates. If scheduling-specific data isn't set on the resource directly, it inherits from its Resource Type.

> [!note] This entry is distinct from the Manufacturing area's [[3-Resources/Glossary/Define Resources|Define Resources]], which is about Work Center machine/tool resources — a different concept under the same activity name.
