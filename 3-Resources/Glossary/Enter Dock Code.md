## Summary

Dock codes are basic data (a Dock Codes tab in Procurement Basic Data) identifying the specific receiving dock(s) at a site where incoming deliveries should arrive. Assigning a dock code to a purchase order or supplier relationship helps warehouse staff and delivery drivers route physical deliveries to the correct dock, which matters most at larger sites with multiple receiving points.

> [!note] Confidence: moderate
> Confirmed to exist as a Procurement Basic Data tab; the precise usage/connection points were not confirmed in a dedicated source.
