## Summary

Supplier message data covers the EDI/electronic-messaging configuration for a supplier — which message types (e.g., order, order response, price catalog/PRICAT) the supplier can send and receive, and the technical parameters (partner IDs, message formats) needed for those exchanges. This underpins scenarios described elsewhere in Purchasing, such as receiving supplier agreement price updates via a PRICAT message.

> [!note] Confidence: moderate
> The role of EDI/message exchange with suppliers is confirmed generally by the Supplier Agreement documentation's references to receiving PRICAT messages; the specific "Enter Supplier Message Data" screen and its fields were not independently confirmed.
