# Define Severity Criteria

## Summary

Severity Criteria are the basic data used to score the "S" dimension of an FMEA (Failure Mode and Effects Analysis) — how serious the consequence of a given failure mode would be if it occurred, typically scaled from "no effect" up to "catastrophic." Along with [[3-Resources/Glossary/Define Occurrence Criteria|Occurrence]] and [[3-Resources/Glossary/Define Detection Criteria|Detection]] criteria, this feeds the Risk Priority Number (RPN) calculation used to rank and prioritize failure modes for corrective action.
