## Summary

IFS Cloud supports entering a purchase part's description in multiple languages, so users viewing the part in a different session language see the description translated rather than only the original entry language. This activity is about populating those language-specific description records for a purchase part so international users and multi-language purchase documents display the part correctly.

> [!note] Confidence: moderate
> Based on IFS Cloud's general multi-language part-description capability; a source describing this exact BDR line for purchase parts specifically was not found.
