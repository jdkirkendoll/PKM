# Override Default Cost Template for Part Cost Group

## Summary

Every Part Cost Group has a default cost template assigned at header level, and this activity lets an administrator substitute a different template for that group (or for specific parts within it) without changing the group's base default. The override is used when a subset of parts needs a different mix of cost buckets/elements than the rest of the group — for instance to run an alternative or "what-if" costing scenario, or to give a product family its own calculation logic — while preserving the original default for everything else. This override can be set from the Part Cost Group window itself, distinct from the narrower, cost-set-specific override available on Part Cost Group/Cost Set.
