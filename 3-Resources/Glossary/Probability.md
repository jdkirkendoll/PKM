# Probability

## Summary

Probability represents the chance of winning a lead or opportunity, expressed as a level/percentage. Each stage of a CRM Process template can define a default probability (e.g. Qualify=20%, Propose=50%, Negotiate=75%, Close=100%) which is automatically applied when an opportunity or lead moves into that stage; the process can optionally force this value so the user cannot override it manually. In IFS Cloud's CRM analysis model, Probability is exposed as the BusinessProbability dimension (code + description) built on the business activity fact table.
