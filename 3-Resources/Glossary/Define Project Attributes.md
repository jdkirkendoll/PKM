## Summary

Custom attributes attached to a Service Project, following the same general attribute pattern documented for this suite's Resource Attribute Manager (system-defined and user-defined attributes attached to an object, used for grouping/filtering/finding data with specific characteristics).

> [!note] Confidence: low
> The Attribute Manager pattern is confirmed generally; its specific application to Projects was not documented and is inferred by analogy.
