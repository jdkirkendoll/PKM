## Summary

Milestone/Stage Payment templates define a reusable set of steps to be performed and approved over the life of a purchase order line — useful for high-value, long-lead-time purchases where the supplier is paid in stages tied to verified progress rather than all at once on receipt. Each template specifies the purchase payment type, the order and expected lead time of the steps, and (for staged payments) what percentage of the total order line amount each stage represents, with the percentages required to sum to 100%. A default template can be set per purchase part and supplier so new purchase order lines pick it up automatically.
