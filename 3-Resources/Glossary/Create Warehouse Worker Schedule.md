## Summary

Warehouse task functionality requires defined working schedules for each warehouse worker so the system knows their availability and can plan/assign tasks accordingly. A worker schedule is built on top of a calendar and determines when a worker is expected to be on shift and able to pick up released warehouse tasks such as pick lists and transport tasks.
