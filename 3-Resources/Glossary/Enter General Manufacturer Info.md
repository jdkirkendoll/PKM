## Summary
This activity registers the general information for a manufacturer — such as its name, association number, default language, and country — in the Manufacturers window, which then appears in the Part and Part Manufacturers windows wherever that manufacturer is connected to a part. The manufacturer must first exist in the Enterprise component with Party Type Identity set to Manufacturer. Once registered, a manufacturer can be connected to one or more parts on the Part Manufacturers page, and any change to the approval status or manufacturer part number is logged to a manufacturer history table so the changes can be traced later; all manufacturer connections on an engineering part must be removed before that part itself can be deleted.
