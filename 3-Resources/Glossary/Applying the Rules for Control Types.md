# Applying the Rules for Control Types

## Summary

A control type is a code, or piece of system data, that can be traced back to the object of a posting — for example a part, customer, project, or purchase group. In IFS Accounting Rules, each posting type is configured with a control type that tells the system where to pull the value for a given code part from at transaction time (rather than requiring the value to be entered manually). "Applying the rules" is the act of assigning the correct control type to each posting type/code part combination so that every business event automatically produces a complete, correct code string.
