## Summary

Configures the EMPLOYEEID company property (optionally combined with EMPPREFIX for a text prefix and EMPMASK for zero-padding) so that new employees registered through New Employment are automatically assigned the next sequential employee number instead of requiring manual entry. If the company isn't connected to this property, numbering falls back to the global Enterprise Identity Series.
