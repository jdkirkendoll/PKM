# Create Sub Status

## Summary

Sub Status is basic data that supplements a Sales Contract's main status with a more granular, globally-defined value. IFS Cloud documentation specifically calls this out during the Negotiate stage of a contract's lifecycle: "It is likely that the supplier and customer go through multiple negotiation processes throughout a contract's life cycle. An additional status—a sub status, is available to identify such processes and they can be defined globally in the system." Setting up sub statuses lets an organization track exactly where a contract sits within a broader stage, such as which round of negotiation is underway.
