## Summary

An IFS Community forum thread confirms a "Rules" screen exists within PSO where Commit Rules are defined — governing how/when the automatic dispatch service commits an activity to a resource (e.g. requiring the resource to actually be logged on before auto-committing). Individual rules can then be added to a Rules Collection and linked to a Resource Type. "Rule Collection" is also confirmed as a documented page name in IFS Cloud's own Schedule Work Tasks with Scheduling Engine documentation, corroborating that Rules and Rule Collections are a real, related pair of concepts in this suite.
