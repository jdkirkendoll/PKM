## Summary

Companion configuration to "Define Additional Attributes required for sampling" within PSO's Predictive Durations/archiving mechanism: this data point selects which entities (e.g., completed tasks, activity types, locations) and which of their attributes are actually captured each time the archiving service takes a snapshot for historical duration analysis, as described in IFS Cloud's Schedule Archive Guide reference.

> [!note] Confidence: moderate
> The archiving/snapshot mechanism is confirmed in IFS Cloud documentation; the exact configuration screen for choosing sampled entities/attributes was referenced only at a high level ("Refer to Archive/Snapshots page") rather than fully documented in what was found.
