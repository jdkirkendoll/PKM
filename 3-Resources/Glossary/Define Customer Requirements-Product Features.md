# Define Customer Requirements/Product Features

## Summary

This basic data defines the lists of customer requirements and corresponding product features used in IFS Cloud's Quality Function Deployment (QFD)-style costing analysis — the "voice of the customer" side of a House-of-Quality-type matrix that cross-references what customers want against the product features that deliver it. Once defined, requirements can be weighted using Define CVA Importance so that costing/value analysis can judge which product features (and their associated costs) contribute most to customer-perceived value, informing target costing and value-engineering decisions.
