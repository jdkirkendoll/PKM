## Summary

Wage codes are the basic units IFS uses to classify pay, absence, and time results (normal hours, overtime, sick pay, and so on). This activity sets up the calculation parameters attached to each wage code in the IFS/Payroll component so the payroll engine knows how each code should be valued, taxed, and reported once time and absence data is transferred to it from Time and Attendance.
