## Summary
Verify Default Values is a Product Data Management basic-data activity performed in the Product Basic Data/Defaults window. An administrator reviews and, if needed, changes system-wide defaults such as the default unit of measure code, the default develop level applied to new revisions, whether Replace Revision functionality is enabled for part revisions, and the default PDM site used for cost calculations. Because these are system defaults rather than hard-coded values, changing them here affects all application users without any program modification. Getting these defaults right up front reduces the amount of manual data entry required when engineering parts and revisions are created later.
