## Summary

Beyond a worker's schedule, warehouse management needs basic data on every individual worker to know their detailed availability and capabilities — which task types they can perform and which inventory location groups (zones) they're allowed to work in. This worker-level information, combined with the task-type/location-group matrix, is what the system uses to determine which warehouse tasks a given worker can be automatically offered or manually assigned.
