## Summary
A Main Group is the broadest, most general level of engineering-part classification in IFS PDM — coarser than Part Class and Standard Name — with examples like "IT material" or "office equipment." Main groups are created in the Product Basic Data window's Main Groups tab by entering an alphanumeric Part Main Group ID and a description; once defined, part classes become selectable on the Engineering Part window. Rather than relying on standard names alone, IFS recommends building this hierarchical structure (main group > class > standard name) so parts can be filtered and queried by category in reports and searches.
