# Apply Changes to Cost Set

## Summary

This activity commits a cost-set-scoped template override (or other cost-set-level costing change) so it actually takes effect for the parts costed under that Cost Set — the change is propagated to the relevant part cost records rather than remaining a staged setting. It is the counterpart, at the Cost Set level, to Apply Changes to Part Cost Group, and follows on from Override Default Cost Template for Cost Set in the standard costing basic-data setup sequence.
