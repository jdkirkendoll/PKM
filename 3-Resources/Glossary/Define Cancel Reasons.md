# Define Cancel Reasons

## Summary

Cancel Reasons are basic data — a list of values (or free text) that a user selects when cancelling a quality-related record, such as an analysis or inspection, so the cancellation is tracked with a documented reason rather than left unexplained. This gives visibility into why quality activities were cancelled when reviewing history or running reports.
