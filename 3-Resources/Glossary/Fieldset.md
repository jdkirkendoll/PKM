# Fieldset

## Summary

A Fieldset is a reusable, named group of [[3-Resources/Glossary/Field|Field]]s defined once for an entity (`fieldset MySet for AsBuiltConfiguration { field PartNo; ... }`) and then reused across multiple lists, groups, cards, or search contexts without repeating the field declarations. It supports the same variant field types a plain Field does (Address Field, Badge, Currency/Measure, Date Range Field, Date Time Picker, Drop-down List, List of Values, Multiline, Static, Toggle Button), plus `fieldorder` and `exclude` properties for customizing how a given usage renders it.
