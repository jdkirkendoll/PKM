## Summary

This activity configures which attributes appear in the tooltip shown when a dispatcher hovers over an activity (a scheduled Work Task/Request Task) in the Scheduling Workbench or Dispatch Console — for example activity type, SLA status, or customer name — so key context is visible without opening the full record. IFS Cloud's own Work Processing documentation confirms tooltips are a supported feature of the Dispatch Console/Gantt for surfacing contextual details per element.

> [!note] Confidence: low
> The general existence of tooltips in this suite's Gantt views is confirmed; the specific "attributes" configuration screen for them was not documented in any source found.
