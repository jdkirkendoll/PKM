## Summary

IFS/Project Reporting uses a defined set of posting types (e.g. PRJC1/PRJC2 for project personal costs and their counter-booking, PRJT1/PRJT2 for project time, PRJI1/PRJI2 for taxable/non-taxable invoicing, and PRJW1-PRJW6 for work-in-progress) to control exactly which debit and credit postings are generated for each project business event. This activity defines/reviews that posting-type configuration as part of Accounting Rules setup for Project Reporting.
