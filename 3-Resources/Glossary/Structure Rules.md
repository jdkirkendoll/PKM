# Structure Rules

## Summary

Structure Rules are back-office configuration rules that operate at the configuration-structure level, deciding — via a Boolean condition similar to an IF/THEN statement, evaluated against a configured part's characteristic and option values — which configuration structure alternate is selected for that specific configuration. When a rule's condition is true, its actions (Set, Declare, or Insert) can modify attributes, derive new characteristic values, or insert additional structure records. Structure Rules require IFS/Configuration Back Office and IFS/Configuration Characteristic to be installed, a configurable part defined in Inventory Part, and a configuration structure already defined for that part.
