# Define Audit Type

## Summary

Audit Type classifies the nature of a Quality Audit — for example internal vs. external, or by the kind of process/area being examined. IFS documentation confirms the internal/external distinction is a fundamental split in how audits are categorized: internal audits are carried out by an auditor within the organization, external audits by an outside auditor.
