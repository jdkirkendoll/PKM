## Summary

A Scheduling Resource Type classifies resources used within a company for the scheduling engine, confirmed as its own basic-data concept in IFS Cloud's PSO documentation ("Scheduling Resource Type" page). Each resource type can be set up with the start and end locations for a work shift, maximum travel hours, and scheduling costs (cost per hour, cost per overtime hour). If a specific resource doesn't have its own scheduling data defined, it inherits these values from its connected Resource Type — so Resource Types act as sensible defaults as well as a classification.
