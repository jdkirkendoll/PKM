## Summary

A Modelling Dataset is a page/concept confirmed in IFS Cloud's Planning and Scheduling Optimization (PSO) documentation, alongside the general Dataset concept: a Dataset is used to transfer data to PSO and defines how data should be scheduled, including the time horizon for the scheduling problem (Scheduling Work Days + Appointment Work Days) and the time zone the data is scheduled in. A "modelling" dataset specifically is used for what-if or capacity-planning style scenarios — consistent with the "Distributed" process type documented for capacity planning — separate from a live production scheduling dataset.

> [!note] Confidence: moderate
> The Dataset concept and Modelling Dataset page are both confirmed to exist in IFS Cloud's PSO documentation, but the specific distinction drawn between an ordinary dataset and a "modelling" dataset was not spelled out in the source found.
