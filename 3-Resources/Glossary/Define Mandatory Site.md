# Define Mandatory Site

## Summary

This basic data setting makes Control Plans mandatory for **every** part received at a given site, regardless of the individual part. It's the site-wide counterpart to [[3-Resources/Glossary/Define Mandatory Part|Define Mandatory Part]] — instead of flagging specific parts, it flags an entire site as requiring an active Control Plan connection before receipt into stock can complete.
