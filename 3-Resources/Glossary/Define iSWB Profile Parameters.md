## Summary

iSWB is the Scheduling Workbench, the web interface for IFS Planning and Scheduling Optimization (PSO). This data point sets profile-level parameters that govern Workbench behavior for a given group of users — for example, the documented `ReasonRequired` parameter, which when enabled forces users on that profile to enter a reason comment for every manual change they make to an activity in the Workbench.

> [!note] Confidence: moderate
> The ReasonRequired parameter and its behavior are confirmed via IFS Community discussion, but the full set of parameters available on an "iSWB Profile Parameters" screen was not enumerated in any source found.
