## Summary

The inspection location is where parts are moved for quality inspection when the receive case demands it (e.g., Receive into Arrival/Inspect at QA, or Receive into QA/Inspect at QA). Like the arrival location, IFS Cloud resolves the inspection location by priority: user-entered, then a default set on the inventory part, then a default on the site, then the last location used. Inspection results can still be reported from any location type (arrival, inspection, or stock) if the parts happen to have been moved elsewhere.
