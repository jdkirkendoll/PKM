## Summary

In this suite, "skills" that matter to the scheduling engine are confirmed to be sourced from Resource Groups (with an optional proficiency), certificates and competencies held by the resource's HR employee record, and the sites the resource's user has access to. For an activity to be allocated to a resource, the resource's skills must match the skills the activity requires. Whether "Define Skills" itself is a single unified master-data screen for entering standalone skills (as distinct from Resource Groups/certificates/competencies) was not confirmed, but it clearly feeds this matching mechanism.

> [!note] Confidence: moderate
> The skill-matching mechanism and its sources (Resource Groups, certificates, competencies) are confirmed; a distinct standalone "Skills" master-data screen as implied by this BDR row's name was not separately documented.
