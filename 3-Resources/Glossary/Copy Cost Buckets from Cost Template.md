# Copy Cost Buckets from Cost Template

## Summary

This activity copies the set of cost buckets already connected to one Cost Template onto another, so a new template for a similar product family or site can reuse an existing bucket configuration instead of connecting each bucket manually. It fits into the broader pattern IFS Cloud Costing uses elsewhere for copying cost structures — for example, a "Replace Cost Template Occurrences" option exists when copying a cost set, to swap the template used on the copied records — and IFS Community setup discussions describe organizations building separate cost templates per product family, each with its own buckets and elements, which this kind of copy activity would streamline.
