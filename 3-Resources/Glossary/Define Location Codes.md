# Define Location Codes

## Summary

A Location Code records *where* a non-conformance was found or occurred (e.g. a physical location, process step, or facility area) on an NCR. It's one of the standard NCR chart filter fields, used alongside [[3-Resources/Glossary/Define Severity Codes|Severity]], [[3-Resources/Glossary/Define Source Codes|Source]], and [[3-Resources/Glossary/Define Root Cause|Root Cause]] to analyze where quality problems are clustering.
