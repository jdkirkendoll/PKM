# Inventory Group

## Summary

Inventory Group is basic data used to classify Inventory Parts as part of the same Inventory-area setup that includes Commodity Groups, Product Families, and Product Codes. In practice it works alongside these other grouping fields to categorize parts for reporting, planning defaults, and stock control — the specific mechanics of the Inventory Group field itself (as distinct from Commodity Group) were not pinned down to a single, dedicated IFS Cloud documentation page during this research.

> [!note] Confidence: moderate
> No IFS Cloud documentation or Community page was found that describes an "Inventory Group" field/window by that exact name, distinct from Commodity Group. It appears in the source BDR process-model documentation as one of the Inventory basic-data setup tasks (alongside Commodity Groups and Product Families), so this entry treats it as a related part-classification grouping in that same basic-data set. Confirm the exact field/window in your own IFS Cloud instance (Inventory Management > Basic Data) before relying on this for configuration.
