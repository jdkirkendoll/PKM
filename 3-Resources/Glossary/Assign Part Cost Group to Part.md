# Assign Part Cost Group to Part

## Summary

This activity connects an individual inventory part to a previously defined Part Cost Group, so the part inherits that group's default cost template — and, through the template, its cost buckets and cost elements — for cost calculation purposes. It removes the need to configure a cost template on every part one at a time: instead, a part is placed into the appropriate cost group (e.g., a manufactured-parts group or a purchased-parts group) and picks up the correct default costing setup automatically. Parts can later have the group's default template overridden for a specific cost set if a different calculation approach is needed for that part.
