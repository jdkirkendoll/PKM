# Define Audit Group

## Summary

An Audit Group is basic data used to organize related audits together — for grouping and reporting purposes rather than defining the audit content itself. It sits alongside [[3-Resources/Glossary/Define Audit Type|Audit Type]] as one of the classification fields used when setting up a Quality Audit.

> [!note] Confidence: moderate
> Public IFS documentation describes what a Quality Audit is in general but doesn't spell out the specific role of Audit Group vs. Audit Type field-by-field. This description is a reasonable functional inference; confirm the exact behavior in your own IFS Cloud instance before treating it as authoritative.
