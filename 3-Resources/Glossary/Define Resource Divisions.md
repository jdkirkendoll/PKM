## Summary

Likely assigns a resource to one or more Divisions (see "Define Divisions"), controlling which organizational/geographic scope that resource belongs to — conceptually parallel to the confirmed Resource Region assignment (which sets region availability for a resource under Automatic or Manual Scheduling) and to the Object Group access model used to scope Scheduling Workbench visibility.

> [!note] Confidence: low
> Divisions themselves aren't confirmed as a documented concept in the sources found; this entry is inferred by analogy with the confirmed Resource Region mechanism.
