## Summary

Absence category groups related absence wage codes (e.g. all sickness-related codes, or all types of paid leave) for reporting and analysis purposes, and is retrievable via the Get Absence Category calculation-formula function which looks up the category defined on the Wage Code page for a given absence wage code.
