## Summary
Product Type is an optional classification used to group Products (in the Products and Models / product catalog part of Design Standard Product) by general kind. Product Types are set up in the Product Basic Data window's Product Type tab, each given an ID of up to 10 alphanumeric characters and a description. Products can then be connected to a product type, and queries or reports can be filtered to a selected product type. It isn't required to create a product, but IFS recommends using it once an organization is managing many products, since it makes them easier to organize and retrieve.
