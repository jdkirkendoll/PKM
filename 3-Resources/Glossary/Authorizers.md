## Summary

Authorizers are the people registered as allowed to approve purchase requisitions and/or purchase orders. IFS Cloud supports six ways to organize them: individual authorizer, group authorizer (several authorizers grouped so any one member can approve), project role authorizer, position authorizer (tied to an organizational position such as Purchasing Manager), requisitioner authorizer (only the requisitioner who created the line can authorize it), and buyer authorizer (only the buyer on the document can authorize it). Authorizers can also be used as control types in posting control, and substitutes can be defined for an authorizer for a specific period (e.g., vacation).
