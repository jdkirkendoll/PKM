## Summary

An Appointment Template enables a pattern of requests to be defined for appointment booking with IFS Cloud's Planning and Scheduling Optimization (PSO). Rather than the user manually specifying every candidate time slot, the system automatically generates appointment requests over the appointment booking period according to the template's Appointment Mode (Appointment to Start / Appointment to Complete), Time Zone, Appointment Window Length, Number of Slots, Day Pattern, and an Auto Request option. Because the Appointment Booking Engine (ABE) is designed to respond quickly, IFS recommends not requesting offers for more than 20 slots at a time. Each template has one or more Appointment Template Items attached, and a default template must be set on the relevant Scheduling Activity Type for appointment booking to work.
