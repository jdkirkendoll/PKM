# Define Root Cause

## Summary

Root Cause is the underlying reason a non-conformance happened — examples cited in IFS documentation include lack of training, defective raw material, or defective equipment. It's associated with an NCR when the report is created, and it's the field that feeds into Corrective and Preventive Action (CAPA): CAPA is the systematic investigation of the root cause, aiming either to prevent recurrence (corrective) or prevent occurrence in the first place (preventive).
