## Summary

Links a default Appointment Template to a Scheduling Activity Type so that appointment booking works automatically for activities of that type. IFS Cloud documentation states this directly: "a default appointment template should be set for the Scheduling Activity Type to perform appointment booking." The Appointment Template itself defines the appointment mode, time zone, window length, number of slots, day pattern, and whether a request is auto-sent to the Appointment Booking Engine (ABE) as soon as the appointment booking page opens.
