## Summary
This basic-data activity sets up the three mandatory pieces of data needed before any Change Request (CR) or Change Order (CO) can be created: CR Levels (priority groupings for requests), CR Types (classifications of requests), and CO Action Causes (the reasons behind a change order). Each is defined on its own tab in the Change Management Basic Data window with an ID (up to 10 characters) and a description, and at least one record of each type must exist before the change-management workflow can be used. CRs capture and evaluate proposed engineering changes and move through Preliminary, Active, Processed, and Canceled statuses; approved CRs are then fulfilled by a CO, which registers, plans, and tracks the actual implementation of the change through its own Preliminary/Analyzed/Approved/Performed/Completed/Canceled lifecycle.
