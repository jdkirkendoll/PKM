## Summary

A return cause records why a specific quantity on a receipt line was returned to the supplier rather than accepted — set per line in the Register Inspection Results dialog, alongside a return type of Return for Rework (supplier reworks the parts) or Return for Credit (supplier credits or a replacement order is created). Return causes are set up on the Return Causes basic-data page and, along with scrapping causes, let a company analyze recurring supplier quality problems.
