# Further Detail Activity Cost Driver

## Summary

This data point covers the additional attributes entered when setting up an Activity Cost Driver beyond its ID and description, in the Activity Cost Drivers window. A documented setup exercise fills these in as an Overhead Type, an Activity Driver Source number, and a Factor Percentage, which together tell the system where the driver's usage data comes from and what share of the associated overhead it represents. This detail is what lets the driver's rate calculation (cost center cost divided by estimated driver usage) resolve to a concrete per-unit cost that flows into the activity's cost bucket.

> [!note] Confidence: moderate
> IFS Cloud documentation does not clearly separate "Define Activity Cost Driver" from a distinct "Further Detail" step under those exact names — this entry infers the further-detail fields (Overhead Type, driver source number, Factor Percentage) from a training exercise walkthrough of the same Activity Cost Drivers window, rather than from a dedicated documentation page using this BDR wording.
