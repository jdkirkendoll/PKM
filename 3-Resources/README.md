# Resources

Reference material not tied to a specific project or area — things you'd look up rather than act on.

`Guides/` holds structured guides written up from research (yours or Claude's), whether sourced from the web, synthesized from your own notes, or both. Give each guide frontmatter so it's queryable from the dashboards:

```yaml
---
topic: 
source: web        # web | notes | mixed
created: 2026-08-25
tags: [guide]
---
```
